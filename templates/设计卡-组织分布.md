# 设计卡 · 组织分布

> **用途**：组织分布（BD）实验的实验前设计卡骨架（研究问题 → 变量 → 对照 → n → 统计预注册 → 组织清单 → 时间点 → 动物用量 → 处理与换算 → 伦理 → 变更记录），可直接复制填写。
> **对应工作流**：`workflows/06-组织分布`（§检测方法选择 / §取材时间点 / §取材组织 / §组织处理详细步骤 / §数据计算 / §动物用量与可行性评估）。
> **门禁指针**：对照 `VESI-ENGINE.md` §3「设计定稿」行（换算复算 + power 记录 → 一致）；结果阶段的浓度换算与靶向效率计算同过该行。对应模块 V-M2。

---

**填写说明**

- 所有数值型占位一律用 `<…>`；组织清单、时间点、每组动物数、取材量、离心与提取条件均按 `workflows/06` 对应小节与项目口径正本填写，本卡不预置数值。
- 组织清单按优先级分层勾选（优先级标注见 `workflows/06` §取材组织）；时间点必须由 PK 数据支撑（`workflows/06` §取材时间点）。
- 动物用量必须写成可验算的矩阵式（时间点数 × 组数 × 每组动物数），并按 `workflows/06` §动物用量与可行性评估 向导师 / 伦理委员会如实报备。
- 方案最终批准 = 人（不可替代，`workflows/_SHARED.md` §4）；口径变更留修订记录。
