# 设计卡 · 体外释放

> **用途**：体外释放实验的实验前设计卡骨架（研究问题 → 变量 → 对照 → n → 统计预注册 → 浓度链 → 时间点 → 伦理 → 变更记录），可直接复制填写。
> **对应工作流**：`workflows/04-体外释放`（§实验设计 / §采样时间点设计 / §释放动力学模型 / §累积释放率计算 / §实验对照）；制剂输入见 `workflows/03-制剂制备与表征`。
> **门禁指针**：对照 `VESI-ENGINE.md` §3「设计定稿」行（换算复算 + power 记录 → 一致）；对应模块 V-M2。

---

**填写说明**

- 所有数值型占位一律用 `<…>`；本卡不预填任何实验数值，参数取值按 `workflows/04`（及 `03` 表征口径）与项目口径正本执行。
- 「统计方法预注册」必须在实验前定稿并签名（`workflows/08` §统计方法速查 铁律：统计方法在实验前确定，非事后选择）；定稿后任何改动只进 §10 变更记录，不改正文。
- 换算链必须写成可复算算式（含单位），并在设计定稿门禁处由第二人复算；口径变更留修订记录（`workflows/_SHARED.md` §整改动机审计 · 如实报告不变式）。
- 方案最终批准 = 人（不可替代，`workflows/_SHARED.md` §4）。
