# 实验记录模板

> **用途**：单次实验的结构化记录骨架（日期 / 实验项 / 目的 / 人员 / 材料批次 / 实际执行步骤 / 原始数据路径 / 观察与异常 / 结论与下一步 / 签名）。
> **对应工作流**：`workflows/12-实验执行与排障`（§实验记录规范 / §数据管理 / §排障框架 / §失败复盘模板）；领域参数以 `workflows/03–07` 对应实验为准。
> **门禁指针**：对照 `VESI-ENGINE.md` §3「记录归档」行（字段比对 → 字段齐；原始数据不可改；记录↔文件路径对应）；对应模块 V-M3。

---

**填写说明**

- 时间写 `YYYY-MM-DD`（跨日、跨时段记录写清起止时刻）；追溯节点记录到分钟，「操作时刻」列不得留空。
- 「操作步骤」栏只记**实际执行**（含偏离与偏离原因），不复制设计卡原文；设计卡是计划，本记录是事实。
- 原始数据只读归档：命名规则、备份份数、溯源链按 `workflows/12` §数据管理 执行；本记录中的路径必须指向真实存在的文件（门禁机械核对）。
- 出现异常按 `workflows/12` §排障框架 六层逐层排查，并在 §7 写下排除依据；重大失败另起 §失败复盘（模板见 `workflows/12`）。
- 签名行不可省：记录人 + 复核人；口述+代录须标注真实执行者（`VESI-ENGINE.md` §1 V-M3 降级列）。
