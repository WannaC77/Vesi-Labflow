# 设计卡 · 排泄

> **用途**：排泄（粪 / 尿为主方案，胆汁为进阶可选）实验的实验前设计卡骨架（研究问题 → 变量 → 对照 → n → 统计预注册 → 方案分层 → 收集窗分段 → 样品处理 → 计算链 → 伦理 → 变更记录），可直接复制填写。
> **对应工作流**：`workflows/07-排泄与代谢`（§方案分层 / §胆汁排泄实验 / §尿液排泄实验 / §粪便排泄实验 / §排泄率计算）。
> **门禁指针**：对照 `VESI-ENGINE.md` §3「设计定稿」行（换算复算 + power 记录 → 一致）；结果阶段的排泄率 / 回收率计算同过该行。对应模块 V-M2 / 下游 V-M5。

---

**填写说明**

- 所有数值型占位一律用 `<…>`；收集窗、收集频次、离心与提取条件、样品处理流程均按 `workflows/07` 对应小节与项目口径正本填写，本卡不预置数值。
- 必须先在 §6 明确选定方案层级（主方案 / 进阶可选），并按 `workflows/07` §方案分层 的口径写明启动条件；未满足条件不得静默升级为进阶方案。
- 收集窗分段表的段名与相别标注按 `workflows/07` 各收集时间点表 的表述填写；分段边界须与给药时刻、给药途径对应。
- 方案最终批准 = 人（不可替代，`workflows/_SHARED.md` §4）；口径变更留修订记录。
