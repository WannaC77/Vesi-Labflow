# 申报-中期-结题映射表模板

> **用途**：申报书承诺点 → 中期检查材料 → 结题材料的逐条对照骨架（只给结构，不代写内容）；用于防止「申报说要做、中期/结题对不上」。
> **对应工作流**：申报书线正本 `templates/申报书线/申报书写作工作流.md`；中期 / 结题节点口径见 `workflows/01-项目管理`（里程碑表）与 `workflows/10-答辩准备`。
> **门禁指针**：对照 `VESI-ENGINE.md` §3「docx」行（`assert_delivery_hygiene` → FAIL=0，若以 docx 交付）＋ `workflows/_SHARED.md` §1 正式交付物门禁（自查 / 吸收回灌 / 对抗性审查 / 决策日志 / 溯源 / 三态）；对应模块 V-M9、runbook RB-V1。

---

**填写说明**

- 表头四列固定：`申报书承诺点 | 中期检查对应材料 | 结题对应材料 | 状态`。
- 第 1 列：**逐条**从申报书正文提取承诺点（承诺的动作 / 指标 / 产出），一条一行，写清申报书中的位置（章节号 / 段落），不得合并或概括；本模板不代写任何承诺内容。
- 第 2、3 列：只写**材料指针**（文件名 / 记录编号 / 图表编号 / 设计卡编号），不在此处抄正文；材料以对应阶段工作流正本为准。
- 状态列取值：`未开始 / 进行中 / 已完成 / 有偏离`；出现偏离必须写明偏离内容与原因，并在决策日志留条目（`workflows/_SHARED.md` §3 交接规范 / §整改动机审计）。
- 时间节点（中期 / 结题的具体月份与前置倒推）不写死在本表：以 `workflows/01-项目管理` 里程碑表与你自己的进度台账（SSOT，本仓不随附内容件）为准。
