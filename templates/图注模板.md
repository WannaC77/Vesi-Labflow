# 图注模板

> **用途**：出版级图件图注的四要素骨架（图号+标题 · 内容描述含 n 与统计 · 方法/条件 · 缩写与统计说明），可直接复制填写；图件与图注同批交付。
> **对应工作流**：`workflows/08-数据处理与可视化`（§图表制作标准 / §本项目专用图表类型 / §常见图表错误）；论文装配口径见 `workflows/09-论文写作`。
> **门禁指针**：对照 `VESI-ENGINE.md` §3「图件」行（三闸 / 双闸 → 过闸）；对应模块 V-M6。

---

**填写说明**

- 图注自含：不看正文也能读懂（`workflows/08` §图表制作标准）。四要素顺序固定：**① 图号+标题 → ② 内容描述（含 n 与统计）→ ③ 方法/条件 → ④ 缩写与统计说明**。
- n 必须写明「独立生物学重复」并注明组数；误差棒含义须声明（SD / SEM 口径按 `workflows/08` §统计微陷阱速查）；显著性标注与精确 p 值按 `workflows/08` §图表制作标准。
- 每个图注的论断须回指 `Claim-Evidence映射表.md` / 证据表编号，不得出现无来源的因果措辞。
- 缩写首次出现在图注内即展开（`workflows/09` §论文 Checklist）；全篇缩写表统一。
- 下方 §示例为**占位示例**（数据一律写作 XX），填真件时整段替换，勿保留示例。

---

## 骨架（逐图复制一份）

```markdown
**图 <N>.** <标题：一句信息量最大、不含因果夸张的陈述句>

<① 内容描述：本图展示了什么指标、在哪些分组 / 条件 / 时间点下的变化；n=XX（<独立生物学重复口径>）；中心值与离散度以 mean ± XX 表示；>

<② 统计：组间比较采用 XX 检验（先经 XX 正态性检验 / 非参数替代 XX），统计量 <t/F/H> = XX，自由度 df = XX，**p = XX**；效应量 XX = XX（95% CI: XX–XX）；多重比较校正方法 XX；>

<③ 方法/条件：模型或样品 <…>；给药 / 处理 <剂量、途径、时长——按设计卡编号引用>；检测方法 <…>；n 的构成 <…>；数据点/重复的独立来源 <…>；>

<④ 缩写与统计说明：XX = XX；XX = XX。误差棒 = XX；显著性标注 *p<0.05，**p<0.01，***p<0.001（p 值报精确值）。图件版本 / 数据文件：<路径>。>
```

## 图注自查（随图件过闸）
- [ ] 四要素齐全且顺序未变
- [ ] n、误差棒含义、检验方法、精确 p 值、效应量（如适用）均已写
- [ ] 图注内缩写全部展开（首次出现）
- [ ] 与坐标轴单位、图内标注一致（图号 / 标题 / 单位 / n 三方对齐）
- [ ] 论断有证据指针（回指 Claim-Evidence / 证据表编号）
