# 答辩 QA 题库模板

> **用途**：答辩 / 中期检查 / 结题 Q&A 题库骨架——五类分栏，每题含「问题 / 要点提示 / 常见追问」，可直接复制逐题填写。
> **对应工作流**：`workflows/10-答辩准备`（§Q&A 高频问题 / §回答策略 / §答辩 Checklist）；问题起点可用同节「必问题 / 进阶问题」清单，但按本课题证据改写。
> **门禁指针**：对照 `VESI-ENGINE.md` §3：无答辩专属行——按 §3「docx」行（`assert_delivery_hygiene` → FAIL=0，若以 docx 交付）＋ `workflows/_SHARED.md` §1 正式交付物门禁（自查 / 对抗性审查 / 溯源 / 三态）执行；对应模块 V-M9。

---

**填写说明**

- 五类固定：研究背景类 / 方法学类 / 结果与解释类 / 局限与展望类 / 伦理与合规类；新增题目只能落在这五类内。
- 每题三栏固定：**问题 / 要点提示 / 常见追问**。「要点提示」内必须含回答骨架（一句话结论先行）与证据指针（表 / 图 / 文献编号 / Claim 编号），不得空泛。
- 「常见追问」写评审可能顺着往下压的第二、第三问；无法预判时写「本类尚未预演，需人工补充」。
- 回答口径与策略（30 秒精炼、不确定时诚实、被质疑时不防御）按 `workflows/10` §回答策略执行；不会答的题不得编数据。
- 覆盖率自查：按 `workflows/10` §Q&A 高频问题 的「必问题 / 进阶问题」逐条核对是否已覆盖，未覆盖的记入下方缺口清单。
