## 🎯 目标

从知识库一键生成申报书初稿，知识库页面自动转换为申报书所需格式。**你只需要说一句"生成申报书初稿"**。

---

## 🔄 工作流

```
用户说: "生成申报书初稿"
    ↓
① Vesi 读知识库（index → 相关页面）
    ↓
② 按申报书章节映射知识库内容
    ↓
③ 自动转换格式（三态标注 → 学术表述）
    ↓
④ 生成初稿（templates/申报书线/申报书-初稿.md）
    ↓
⑤ 审稿人模式自查（问题+修正一并交付）
    ↓
⑥ 你审核 → 修改 → 定稿
```

## 🔄 格式转换规则（三态标注 → 学术表述）

| 知识库中的标注 | 申报书中的表述 |
|---------------|--------------|
| `[事实]` 有文献支撑 | 直接写，附 PMID/DOI 引用 |
| `[推断]` 合理未验证 | 改写为"有望/预期/可能" + 标注"需实验验证" |
| `[假设]` 待检验 | 改写为"拟验证" + 列入研究内容 |
| `[[wikilinks]]` | 展开为完整术语/概念名 |
| `## Related literature` | 并入参考文献列表 |
| 表头英文 | 保留（直接进申报书）|

## 📝 申报书初稿生成 Prompt（Vesi 内部使用）

```markdown
你是目标赛道申报书初稿生成器。任务：
1. 读知识库: kb/ (先读 index.md + SCHEMA.md)
2. 按《申报书写作工作流.md》结构生成初稿，保存到 templates/申报书线/申报书-初稿.md
3. 转换规则: [事实]→直接写附引用, [推断]→"有望/预期", [假设]→"拟验证"
4. 创新点 ≤3 条，每条有实验落点
5. 技术路线 mermaid 闭环
6. 完成后以审稿人模式自查: 列出发现的问题 + 修正建议
```

## ⚠️ 边界说明

- 初稿 ≠ 定稿：生成后必须经审稿人自查 + 你审核 + 导师把关
- 文献引用：只引用知识库中真实存在的文献（PMID/DOI 可查）
- 各校申报书模板不同：初稿按通用结构，提交前对照学校模板调整
