# 设计卡 · 体内PK

> **用途**：体内药代动力学（PK）实验的实验前设计卡骨架（研究问题 → 变量 → 对照 → n → 统计预注册 → 剂量换算链 → 给药与采血 → 伦理 → 变更记录），可直接复制填写。
> **对应工作流**：`workflows/05-体内药代动力学`（§实验设计 / §给药方案 / §采血方案 / §体内释放表征 / §PK参数计算）。
> **门禁指针**：对照 `VESI-ENGINE.md` §3「设计定稿」行（换算复算 + power 记录 → 一致）；本卡同时是 §3「PK」行（参数完整 + 口径声明）的实验前依据。对应模块 V-M2 / 下游 V-M5。

---

**填写说明**

- 所有数值型占位一律用 `<…>`；剂量、体积、时间点、采血量、上限值等一律按 `workflows/05` 对应小节与项目口径正本填写，本卡不预置数值。
- 给药方式与采血时间点先按 `workflows/05` §给药方案 / §采血时间点设计 选定「参数族」，再在本卡落具体值；采样点覆盖要求（分布相 / 消除相）与采血上限红线按同节执行。
- 统计方法预注册必须实验前定稿（`workflows/08` 铁律）；NCA / 房室模型的软件、权重方案、拟合优度判据在实验前登记，结果阶段只回填、不改判据。
- 方案最终批准 = 人（不可替代，`workflows/_SHARED.md` §4）；口径变更留修订记录。
