# 精读笔记模板

> **用途**：文献精读的结构化笔记骨架（复制后逐项填写）——证据表与综述引用的上游件。
> **对应工作流**：`workflows/02-文献调研`（§精读笔记模板 / §证据等级评价 / §引用质量审查 / §与知识库联动）。
> **门禁指针**：对照 `VESI-ENGINE.md` §3「文献入库」行（元数据可核验 · 三态 · 检索式可复跑）；作为正式交付物引用时另过 `workflows/_SHARED.md` §1 的溯源检查与三态标注。

---

**填写说明**

- 一行一条事实、一个来源；三态口径正本 = `workflows/_SHARED.md` §5（`[事实]` / `[推断]` / `[假设]`）。若习惯用「已证实 / 推断 / 未知」表述，按同序一一对应填写（已证实→事实、推断→推断、未知→假设），全篇只用一套写法。
- 题录区元数据（作者 / 年份 / 期刊 / PMID / DOI）逐条过 NCBI esummary 实证，搜索摘要只作线索（`workflows/08-数据处理与可视化` §LS-8-5）。
- 证据等级、引用质量、灌水/造假信号、矛盾文献处理，一律按 `workflows/02` 对应小节判定，本模板不重复定义。
- 笔记落盘位置与出链/回链要求按 `workflows/02` §与知识库联动 与 11-知识管理 口径执行。
- 骨架内只填占位符 `<…>`；确无内容的项写「未报告」，不留空白。

---
