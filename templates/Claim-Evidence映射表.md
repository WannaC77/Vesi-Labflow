# Claim-Evidence 映射表模板

> **用途**：论文 / 答辩 / 申报中各条 claim（论断）与其支撑证据的对照表骨架——交付前逐条回指，杜绝无证据论断。
> **对应工作流**：`workflows/09-论文写作`（§论文 Checklist / §迭代循环）；上游为 `workflows/02-文献调研` 证据表 + `workflows/08` 图表。
> **门禁指针**：对照 `VESI-ENGINE.md` §3「docx」行（`assert_delivery_hygiene` → FAIL=0）与 runbook RB-V4（论文线：M4/M5 → M7 → M6 → Claim → 断言）；对应模块 V-M7。

---

**填写说明**

- 表头五列固定：`论断编号 | 论断文本 | 支撑证据（表/图/文献编号） | 强度（强/中/弱） | 风险备注`。
- 一行一条 claim：claim 必须是可被证据证伪的陈述句；同一结论的不同表述合并为一行，不拆分稀释。
- 「支撑证据」必须写到可定位粒度：表号 / 图号 / 证据表编号（E-XX）/ PMID 或 DOI / 数据文件相对路径；写「本实验数据」不算证据。
- 强度取 `强 / 中 / 弱`，与 `证据表模板.md` 同口径；评定参照 `workflows/02` §证据等级评价 与 §引用质量审查（样本量、对照、统计、独立验证、时效性）。
- 无证据或证据不足的 claim：降级为 `[推断]` / `[假设]`（`workflows/_SHARED.md` §5）或直接删除；结论措辞不得超出证据范围（`workflows/09` §Discussion 铁律）。
