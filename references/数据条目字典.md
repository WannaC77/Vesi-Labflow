# 数据条目字典（命名与口径骨架）

> **用途 / Purpose**：统一「项目里每个数字叫什么、什么单位、什么口径、从哪来」——使**任一数字可回溯到原始文件**、**跨轨/跨人可对齐**、**图表与论文取数不换口径**。
> **版本 / Version**：v1.0（2026-09-21 · 生成侧强化批 3 · V-R/V-M3/V-M4）
> **模块指针**：V-R 底座（`VESI-ENGINE.md` §1）｜装载 `workflows/05–08`｜数据唯一正本 = `kb/`
> **纪律（先读后填）**：
> 1. 本卡是**骨架**（条目名 / 类型 / 单位 / 允许值 / 口径 / 占位示例），**不含任何具体实验数值**——数值只存在于原始文件与正本数据表。
> 2. 条目名一律 **snake_case 英文**（图注/正文可写中文，但落表键名不变）；单位一律显式写进列名或 `*_unit` 列，**禁止单位隐含**。
> 3. 任何条目落表前，其「口径说明」栏必须能一句话说清；说不清 = 该条目口径未定，**不得先填数**。
> 4. 与三态标注（事实 / 推断 / 假说）冲突时，**三态规则优先**（见 §3；规则正本在 `VESI-CORE.md` 铁律节，本卡不复制正文）。

---

## 1 · 命名总则

| 规则 | 说明 |
|---|---|
| 结构 | `对象_属性[_条件]`，如 `c_plasma` / `dose_iv` / `cum_excretion_urine_pct` |
| 时间 | 时间点一律 `*_h` 或 `time_point_h`，**单位小时**；非小时口径走 `*_unit` 列声明 |
| 组别 | 组标签 `group_label` 保留原始写法（脂质体组/游离药组/空白组），映射用 `group_id` |
| 单位 | 优先 SI 与药代学惯用单位（`mg/kg`、`ng/mL`、`µg/g`、`h`、`mL`、`g`、`%`）；`µg` 统一写 `µg`（不用 `ug`） |
| 禁写 | 禁止 `<对象>_2`、`final`、`new`、`最终` 这类**无信息后缀**；禁止同一含义出现两种拼写（如 `auc` / `AUC` 混用） |
| 大小写 | 全部小写 + 下划线（`snake_case`）；分析物编码用固定枚举（见 §2 D 族） |

## 2 · 条目表（骨架 · 示例列一律占位）

> 占位约定：`<组名>` / `<动物编号>` / `<数值>` / `<标准编号>` / `<YYYY-MM-DD>` / `<文件路径>` / `<单元格或页码>`。**不得把占位当数值用**。

### A 族 · 标识与分组

| 条目名 | 类型 | 单位 | 允许值/格式 | 口径说明 | 示例占位 |
|---|---|---|---|---|---|
| `study_id` | str | — | `<课题代号>-<年>-<序号>` | 一次实验/一批实验的唯一编号；跨轨共用同一编号 | `<课题>-<年>-01` |
| `track` | enum | — | `目标赛道` / `目标赛道` / `生科` | 材料所属轨道；**数据不分轨**，分轨的只是产物 | `<轨道名>` |
| `group_id` | str | — | `G1`…`Gn` | 组编号，与实验设计卡一致 | `G<整数>` |
| `group_label` | str | — | `<组名>` | 原始组名，保留历史写法；分析时以 `group_id` 为准 | `<脂质体组>` |
| `animal_id` | str | — | `<品系代号>-<序>` | 个体唯一标识，**与笼位/耳号对应关系须在记录中留痕** | `<动物编号>` |
| `matrix` | enum | — | `plasma` / `serum` / `urine` / `bile` / `feces` / `tissue` / `other` | 生物基质；`other` 须在备注写明 | `<基质>` |
| `tissue` | enum | — | 组织枚举（心/肝/脾/肺/肾/脑/肿瘤/…） | 组织名统一用英文键名 + 中文映射表；湿重口径见 `tissue_weight` | `<组织>` |
| `analyte` | enum | — | `IRI` / `SN-38` / `SN-38G` / `total` | 分析物编码**全项目统一**；`total` 须注明计算式 | `<分析物>` |
| `replicate_type` | enum | — | `biological` / `technical` | **生物学重复 ≠ 技术重复**；统计只用生物学重复（`workflows/08` §统计微陷阱） | `<重复类型>` |
| `n_rep` | int | — | `>=1` 整数 | 声明 n 的同时必须声明 `replicate_type` | `<整数>` |

### B 族 · 剂量与给药

| 条目名 | 类型 | 单位 | 允许值/格式 | 口径说明 | 示例占位 |
|---|---|---|---|---|---|
| `dose` | num | `mg/kg` | `<数值>` | **必须声明盐基/游离碱口径**；换算公式与参数记入 `derived_from` | `<数值>` |
| `dose_basis` | enum | — | `free_base` / `salt` / `as_is` | 剂量口径；缺此列 = 剂量不可比 | `<口径>` |
| `route` | enum | — | `iv` / `ip` / `po` / `sc` / `other` | 给药途径；`iv` 须区分推注/滴注 | `<途径>` |
| `dose_volume` | num | `mL/kg` | `<数值>` | 单位体重给药体积 | `<数值>` |
| `dose_conc` | num | `mg/mL` | `<数值>` | 给药液实测浓度（理论值另建条目） | `<数值>` |
| `body_weight` | num | `g` | `<数值>` | 称重时点须声明（给药日/采样日）；**湿重/禁食状态**注明 | `<数值>` |
| `admin_datetime` | datetime | — | `<YYYY-MM-DD HH:MM>` | 给药时刻；时程计算的**零点基准** | `<日期时间>` |

### C 族 · 采样与时间

| 条目名 | 类型 | 单位 | 允许值/格式 | 口径说明 | 示例占位 |
|---|---|---|---|---|---|
| `time_point_h` | num | `h` | `>=0`，允许 0 | **零点 = 给药完成时刻**（须声明）；实际采样时刻与标称时点的偏差须可查 | `<数值>` |
| `sample_datetime` | datetime | — | `<YYYY-MM-DD HH:MM>` | 实际采样时刻（用于偏差核算） | `<日期时间>` |
| `sample_volume` | num | `mL` | `<数值>` | 血浆/尿/胆汁体积；采样方式（是否补液）注明 | `<数值>` |
| `sample_mass` | num | `g` | `<数值>` | 组织/粪样湿重；**干重口径另立条目**，不得与湿重同列 | `<数值>` |
| `collection_interval` | str | `h` | `<t1>-<t2>` | 分段收集（如 0–6/6–12/12–24 h）的区间定义 | `<区间>` |

### D 族 · 检测与浓度

| 条目名 | 类型 | 单位 | 允许值/格式 | 口径说明 | 示例占位 |
|---|---|---|---|---|---|
| `conc_value` | num | 见 `conc_unit` | `<数值>` | 一次测量结果；**原始谱图/工作曲线指针必留** | `<数值>` |
| `conc_unit` | enum | — | `ng/mL` / `µg/mL` / `ng/g` / `µg/g` / `%ID/g` | 单位**逐条声明**；跨单位比较前先换算并留痕 | `<单位>` |
| `dilution_factor` | num | — | `>=1` | 稀释倍数；报告值 = 实测值 × 稀释倍数（公式留痕） | `<数值>` |
| `lod` / `loq` | num | 同 `conc_unit` | `<数值>` | 检出限/定量限；**低于 LOQ 的处置规则**（标 `<LOQ` / 排除 / 计入）须声明 | `<数值>` |
| `recovery` | num | `%` | `0–100`（含范围写法） | 提取回收率/加样回收率**须区分**；样本数 n 同列写明 | `<数值>` |
| `qc_level` | str | — | `<低/中/高>` | 质控水平与允许偏差规则（以方法学文件为准） | `<水平>` |
| `assay_method` | str | — | `<方法名>` | 检测方法（LC-MS/MS、HPLC-UV、荧光等）+ 方法学文件指针 | `<方法>` |

|---|---|---|---|---|---|

## 3 · 三态标注规则（指针 + 落表落法）

> 规则正本：`VESI-CORE.md` 铁律节（**本卡不复制正文**）；本表只定**落表落法**。

| 态 | 落表值 | 含义 | 允许来源 | 落盘要求 |
|---|---|---|---|---|
| **事实**（fact） | `fact` | 原始文件中**直接可读**的记录/数值 | 原始文件、仪器输出、记录表 | `source_file` + `source_locator` + `source_md5` 三件齐 |
| **推断**（inference） | `inference` | 由事实按**明确方法**推导（换算、拟合、统计） | 由 `fact` 行派生 | 必填 `derived_from`（条目 + 公式）+ 方法指针 |
| **假说**（hypothesis） | `hypothesis` | 待验证的判断/解释 | 讨论、假设、机制猜想 | 必填「拟验证方式」；**不得与 fact 同栏混排、不得进结果数字表** |

**纪律**：`state_3` 缺列 = 该行不得参与分析/作图/论文引用；`inference` 行在论文中表述为「推算」而非「实测」。

## 4 · 溯源规则（每数字可回溯到原始文件）

1. **一数一源**：每个数字至少带 `source_file` + `source_locator`；不得出现「来自上版表格」这类无原始锚的传承。
2. **原始文件只读**：原始数据/谱图/记录**永远不覆盖**（对齐 `workflows/08` §数据处理流程 ①）；清洗与派生另存并标 `inference`。
3. **口径变更留痕**：单位、基准、剔除规则任一变更 → 记 `derived_date` + 备注，**不静默重算**（口径类变更须全库精确复查，对齐 `workflows/08` §LS-8-4）。
4. **数字唯一正本**：数据引用自正本（`kb/`），**引用不复制**——产物内不新建平行数据表（跨轨同此纪律，见 `references/跨轨改写卡.md`）。
5. **禁止编造**：任何取不到的数值一律留空并标 `[待补]`；**不得**用估计值/文献值填充本课题数据位。

**可执行验收式**：任取成果件中一个数字，**≤3 步**内可定位到原始文件的具体位置（文件 → 位置 → md5）；任一条做不到即本卡视为未落地。

## 5 · 落表前自查 checklist

- [ ] 条目名符合 §1（`snake_case`、无无信息后缀、无同义双拼）
- [ ] 单位显式（列名或 `*_unit` 列），`µg` 写法统一
- [ ] `time_point_h` 零点基准已声明；实际采样偏差可查
- [ ] 剂量口径（`dose_basis`）已声明；换算公式已入 `derived_from`
- [ ] 生物学重复 vs 技术重复已区分；`n_rep` 与 `replicate_type` 成对出现
- [ ] 浓度单位跨表比较前已换算并留痕；`dilution_factor` 已入公式
- [ ] `<LOQ` 处置规则已声明
- [ ] 累积口径（%ID / %剂量）与图注/正文表述一致
- [ ] 湿重/干重、盐基/游离碱 未混用
- [ ] `state_3` 三态齐全；`hypothesis` 未混入结果数字表
- [ ] `source_file` + `source_locator` + `source_md5` 三件齐（fact 行）
- [ ] 复核人（`checked_by`）已签
