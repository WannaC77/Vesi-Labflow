# Vesi-Labflow 路径与资产清单（包内 SSOT 卡）

> **用途 / Purpose**：本开源包**路径与资产的单一事实来源（SSOT）**——顶层件、目录、分层归属、自建占位符一处登记、全局引用。
> **版本 / Version**：v1.0（公开版）｜配套 `VESI-ENGINE.md`（引擎：模块注册 / 门禁矩阵 / runbook / 交接卡）与 `VESI-CORE.md`（人格：铁律与装载口径）。
> **路径纪律**：本卡所有路径一律**仓内相对路径 + 正斜杠**，以包根为基准；不出现绝对路径、盘符与用户名。
> **防双表纪律**：本卡只维护「顶层件 / 目录 / 占位符」；**资产清单正本在 `VESI-ENGINE.md` §5**（件名 / 相对路径 / 版本 / 模块 / 层 / 状态）——本卡不复制资产表。

## 3 · 分层与自建占位符

| 层 | 内容 | 位置 |
|---|---|---|
| **L0 领域能力**（随包分发） | 引擎、模块规格件、工作流、模板、参考卡、工具、交付脚本 | 包内相对路径（§1 / §2） |
| **L1 配置剖面** | 赛道与体系口径（剂型 / 模型 / 检测口径 / 交付格式） | `VESI-CORE.md` 的配置节；**改配置不改机制** |
| **L2 私有数据**（自建，不随包分发） | 知识库、协作层、校准数据、锚注册 | 占位符见下表 |

| 占位符 | 含义 | 落点 / 起步方式 |
|---|---|---|
| `kb/` | 你的知识库（文献笔记 / 检索记录 / 证据表 / 方法索引） | 包内空目录；schema 见 `workflows/11-知识管理.md` |
| `<共享层>/` | 可选的多 agent / 多人协作层 | 不需要就不建；需要时自建并放共享 SOP（吸收机制见 `workflows/D-ABSORB.md`） |
| `<校准台账>` | 私有校准数据（判据线 / 复发计数 / 整改记录） | `templates/校准台账模板.md`（空白） |
| `<锚注册卡>/` | 私有锚注册（已知答案锚 / 已知档位锚） | `templates/锚注册卡模板.md`（空白）+ 填锚规程见 `references/outcome-anchor-protocol.md` |
| `<venv>/` | 你的 Python 虚拟环境 | 自建；依赖见 `requirements.txt` |
| `<TeX 安装目录>` / `<系统字体目录>` | 本机 LaTeX / 中文字体位置 | 由探测链解析（环境变量 → PATH → 平台探测）；缺件按模块「降级」列标 `[降级]` |

> 占位符不得指向包外绝对路径；新增占位符须先在本节定义，再在文档中引用。

## 4 · 路径写法纪律与自检

- **引用一律仓内相对 + 正斜杠**；引用不得出包（`../X` 属违规写法）。
- **新增 L0 件**：七段齐（目的 / 输入输出 / 接口 / 装载 / 门禁 / 降级 / 样例）→ 落盘 → 登记 `VESI-ENGINE.md` §5 → 回本卡 §2 补目录行。
- **机制不复制**：细节正本在 `workflows/` 与 `modules/`；引擎与本卡只索引。
- **改动后自检**（全 PASS / SKIP 即 rc=0）：

```bash
python tools/env_check.py --selftest          # 环境档位（T0/T1/T2）
python tools/smoke_chain.py --selftest        # 全链冒烟（含黄金数值断言）
python scripts/selftest_scripts.py            # 门禁脚本元自检
python tools/nca.py --selftest                # 领域工具逐个自检
python tools/compartment_fit.py --selftest
python tools/release_fit.py --selftest
python tools/stats_pipeline.py --selftest
```

> 约定：`0` 通过 · `1` 失败 · `2` 用法错误；**SKIP 不算 FAIL**（但须在报告里写明缺件原因）。
