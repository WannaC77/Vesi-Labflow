# outcome 锚注册与校准规程（锚校准协议 · 通用）

> **用途 / Purpose**：把「评审能不能发现问题」「我方材料到什么程度算够」「同材料重评差多少算漂移」三件事，压成**可登记、可复算、可重校**的锚机制。
> **本件性质**：**机制抽象版**——机制全留、实测数值全删、阈值一律参数化。锚是你自己的资产，本件只给骨架与规程。
> **执行入口**：`workflows/_SHARED.md` §2（对抗性审查）· 本规程。
> **上位台账**：`templates/校准台账模板.md`（`<校准台账>`）——锚登记、标准版本与整改历史的正本。
> **版本 / Version**：v1.0（抽象版）。
> **中性声明**：本产品不依赖任何特定 agent / CLI / 调度器；文中「会话 / 独立上下文 / 审查员 / 执行体」均指「任一次可复算的执行单元」，可由人或任意工具承担。
> **总纪律**：**阈值在标定前一律只是经验值**，不得当作结论对外使用；「只建机制、不跑校准」是允许的起点状态。

## 一、为什么需要 outcome 锚（两条锚路线的结构差异）

| 维度 | 路线 A：有公开库 | 路线 B：无公开库（本规程适用） |
|------|-------------|-------------|
| 锚源 | 公开获奖材料库（自建收集） | **无公开库**——已知答案锚样本 + 课题自身历史材料 |
| 锚型 | **已知档位锚**（用已知档位校准评审） | **已知答案锚**（用已知答案键校准评审灵敏度） |
| 校准目标 | 判档命中率 | 缺陷覆盖率（发现数 / 答案键问题数） |
| 判定性质 | 档位判定（可二值） | **覆盖率判定（不可二值）** |

**关键结论**：无公开库不等于「缺锚」，而是**已有的已知答案锚只覆盖了「评审灵敏度」一个轴**，另两轴须自建：

| 轴 | 现状 | 缺口 |
|----|------|------|
| **A. 评审灵敏度轴** | 已建（已知答案锚样本 → 答案键对质，算覆盖率） | — |
| **B. 材料达标轴** | 缺 | 我方材料「到什么水平算够」无参照刻度 |
| **C. 尺度漂移轴** | 半建（只测单项指标，无分档刻度） | 无「同材料重评差多少算漂移过大」的阈值与处置动作 |

**本规程补 B、C 两轴。**

### 2.2 填锚规程（F6）

1. **先建锚、再调阈值**：锚未登记前，一切阈值只算**经验值**，不得作对外口径。
2. **一锚一问**：每个锚只回答一个问题（如「灵敏度门是否偏低」），避免同一锚被反复榨取。
3. **登记卡不登记正文**：每份锚填一张 `templates/锚注册卡模板.md`（中性名 / 类型 / 来源类型 / 落点 / 用途 / 复核记录）；正文只在 `kb/`，不入仓库。
4. **合法与授权**：只用公开、自有或明确授权的材料；他人未公开材料不得入库、不得转述。
5. **可分性与使用限制**：写清该锚能区分哪些判定档位、是否只在某阶段使用、是否禁止外传。
6. **可复跑**：每次用锚做校准，须留**可复跑的命令或脚本**，否则不算证据。
7. **样本不足即描述性**：锚样本不足（经验起点：单轴 < 5 份）时，结论只作**描述性**记录，**禁止**宣称阈值「稳定」或「已达某档位水平」。
8. **隔离与复点**：规则标定样本与验证样本**分离**（A 批定阈值 → B 批验阈值）；锚材料更新后旧结论必须复点。

## 三、B 轴：材料达标轴

### 3.1 问题陈述

只有 A 轴时，只能回答「评审能不能发现问题」，**无法回答「我方材料到什么程度算够」**。这影响两件事：

1. **放行判据缺失**：审查出结果后无法下「可交付 / 不可交付」的判定；
2. **进步无法量化**：只能记「本轮发现 N 条缺陷」，无法判断比上轮好了还是差了。

### 3.2 解决路径：**缺陷密度基准（密度基准法）**（非分数基准）

无官方评分制时 → **不引入分数刻度**（引入即伪精度）。改用**缺陷密度**作可量化基准：

```text
缺陷密度 D = 本轮发现的「致命 + 重大」缺陷数 ÷ 材料千字数
```

以已知档位锚（A2）为**基准值 D₀**（须先按 §五 实测标定），我方同尺度材料算 D₁：

| 判定 | 条件（倍数带宽 = 默认起点，经验值须自行重校） | 含义 |
|------|------|------|
| **达标** | D₁ ≤ D₀ | 缺陷密度不高于已知档位样例 |
| **接近** | D₀ < D₁ ≤ 2 × D₀ | 一个量级内 |
| **不达标** | D₁ > 2 × D₀ | 缺陷密度超已知档位样例一个量级以上 |

> **注**：D₀ 标定前，本轴状态为「**未启用**」；缺 A2 锚时退化为「同类型材料纵向自比」并标 `[降级]`。

### 3.3 构念纪律（防误用）

1. **D₀ 是密度基准，不是分数基准**——不得表述为「我方已达某档水平」，只能说「缺陷密度为已知档位样例的 x 倍」。
2. **只在同文档类型内比**（综述↔综述 / 设计↔设计）；跨类型不比（篇幅与缺陷结构不同）。
3. **D₁ 的发现数必须来自同一评审组**（同批次专家 / 同口径执行体），换组即换尺。
4. **分母口径须声明**（字符数或汉字数，二者不可混比）。

## 四、C 轴：尺度漂移轴

### 4.1 问题陈述

台账侧的「反宽松偏置」条款只覆盖「分数上升」方向，且无漂移阈值。缺两件事：同材料重评差多少算「漂移过大」；漂移超阈值时的处置动作。

### 4.2 阈值设计（**默认起点全为经验值，须自行重校**）

| 指标 | 默认起点 | 处置 |
|------|------|------|
| 同材料、同评审组重评，缺陷数差 | ≤ ±20% | 锚稳定 ✓ |
| | ±20% ~ ±40% | 记 changelog，加注「尺度待观察」 |
| | > ±40% | **判尺度漂移** → 先统一口径复评；复评前输出只作参考 |
| A 轴覆盖率（已知答案锚） | ≥ 70% | 合格 |
| | < 70% | **评审灵敏度不合格**（灵敏度门未过）→ 先重校评审组，再审我方材料 |

### 4.3 漂移样的选择

**首选 B1/B2（自评基准）**——文本冻结、可反复重评、无外部依赖。
**禁用**：正在被持续修改的材料（一边改一边重评 = 同时动尺和物，无法归因）。

### 4.4 跨轮监测口径（三条 · 常设）

1. **绝对计数**：缺陷绝对条数**仅同轮内参考**，**禁止跨轮当作 D₀/D₁ 比较基线**；跨轮表述一律用**区间**（如「某件：9–11 条」）并注明轮次与执行体。
2. **集合判据（主判据）**：同尺（同族分类、同字数口径）下的**核心位置重合率**——≥70% ＝ 定性面稳定 ✓／50–70% ＝ 观察／<50% ＝ 判漂移（须先统一口径复评）。首标定值须自测。
3. **深度预算（执行方式）**：以**固定审查员预算（BP 条款 + 自检表）**为首选；**双评（隔离双跑取均）**保留为 <50% 漂移时的升级动作。
   > 与 §4.2 的关系：±20%／±40% 表为**原始阈值**，按本条 ① 降级为**同轮参考**；跨轮主判据以本条 ② 为准。

### 5.1 执行规格（条款化 · 使步骤 1–3 可照单执行）

> 目的：**不跑校准，也把「怎么跑」定死**——避免解禁时重新设计，避免不同会话各跑一套口径。
> 产出纪律：所有输出按 `workflows/_SHARED.md` §5 做**三态标注**（事实 / 推断 / 假设）——审查所见与计数记 `[事实]`，归因与「为什么会低报」类判断记 `[推断]`，未验证的根因记 `[假设]`。

**S1 · D₀ 标定（步骤 1）**

| 项 | 规格 |
|----|------|
| 输入 | 已知档位锚（A2）全套材料；锚注册卡见 `templates/锚注册卡模板.md` |
| 执行体 | **对抗性审查**（`workflows/_SHARED.md` §2 维度表）——不用其他赛道的打分制 |
| 计数口径 | 只计**致命 + 重大**（一般 / 建议不计）；族分类沿用谱系表，**不另定义族** |
| 分母 | 材料千字数——**须声明字数口径**，且与 D₁ 取同一口径方可比 |
| 输出 | `D₀ =（致命 + 重大）÷ 千字数`，含逐条缺陷清单（族 → 位置 → 摘引）作证据链 |
| 落点 | 本规程执行记录 + `<校准台账>`（锚行 + 版本升版登记） |

**S2 · B1/B2 基线（步骤 2）**

| 项 | 规格 |
|----|------|
| 样本 | B1 = 我方**实验设计**稿；B2 = 我方**研究综述**稿（§2.1 空锚表） |
| 冻结要求 | **样本必须先冻结**（取当轮文件指纹存档）——否则「一边改一边量」无法归因（§4.3 禁用条款） |
| 执行体 / 计数口径 / 分母 | 同 S1（**同一评审组、同一族分类、同一字数口径**，否则换尺） |
| 同类型内比 | 综述 D₁ ↔ 综述类 D₀；设计 D₁ ↔ 设计类 D₀；**跨类型不比**（§3.3 构念纪律 2） |
| 输出 | `D₁(设计) / D₁(综述)` + 判定档（达标 ≤ D₀ / 接近 ≤ 2 D₀ / 不达标 > 2 D₀） |
| 落点 | 同 S1 |

**S3 · 首个漂移样对质（步骤 3）**

| 项 | 规格 |
|----|------|
| 样本 | **首选 B1/B2**（文本冻结、可反复重评、无外部依赖）；禁用「正在被修改中的材料」 |
| 动作 | 同材料、同评审组**重评一次** → 比两次缺陷数与**核心位置重合率** |
| 阈值 | 见 §4.2（计数差）与 §4.4 ②（重合率）；超阈值 → 升级**双评** |
| 输出 | 两次结果 + 差值 + 重合率 + 判定 + 处置 |
| 落点 | 同 S1（并登记为该轴首个「漂移样注册卡」） |

**S4 · 解禁条件（何时可跑）**

1. 你明确撤销「生成侧不动」约束；**或**
2. 你单独授权「**只跑锚标定，不触碰生成侧 / 创新点**」——S1–S3 只对**既有材料**做审查与计数，不改任何生成侧产物、不动判准表、不动创新点，属**可独立授权**的窄口动作；
3. 无论哪条路径，**裁定记录须落到 `<校准台账>` 或本规程执行记录**，注明授权来源与日期。

### 5.1.b 深度预算（Depth Budget · 把「深度」写成可机检条款）

> **问题**：同材料、同尺度、隔离审查员重评 → 缺陷计数可能**同向大幅低报** → 绝对计数不可跨轮比较；根因假设＝审查员的**深度 / 覆盖预算无约束**（执行单元级波动）。
> **处置**：把「深度」写成可执行、可机检的预算条款，再实测标定。

**预算条款（BP-1…BP-7；BP-1/2/3/5/6 = 审查员侧行为约束，须写进评审提示词）**

| # | 条款 | 机检方式 |
|---|---|---|
| **BP-1** | **逐族判定义务**：谱系表**逐族**给出「命中数 + 证据句（段#/表#/节#）」；0 命中须给一句排除理由 | 报告含 N 行族表（缺行 = 不达标） |
| **BP-2** | **强制三步逐项报数**：①三方扫描（编号连续数 / 题名数 / 单位对齐数 / 样本量对齐数）②方法最小字段表（逐字段 有/无/值）③样本量矩阵（实算式 + 总数） | 三步各有独立小节且含数字 |
| **BP-3** | **缺陷最小字段**：id / 维度 / 族 / 严重度 / 位置 / 摘要 ≤40 字 / 方案 ≤30 字 | 逐条可机检 |
| **BP-4** | **密度下限**（组织者侧核对 · ⚠ 不告知审查员，防锚定）：致命+重大条数 ≥ 系数 × 上一同尺轮参考值（系数起点建议 0.8，**经验值，须自行重校**） | 计数比对 |
| **BP-5** | **反注水**：同位置 + 同族**合并为一条**；无位置条目不计；不得为凑数拆分同一问题 | 抽查 + 去重后计数 |
| **BP-6** | **自检一致性**：报告自报 counts 与结构化输出 counts **逐位一致** | 机检 |
| **BP-7** | **双评（隔离双跑）**：同材料由两个隔离上下文独立审查，比两次的**核心位置集合重合率**（≥70% 稳定／50–70% 观察／<50% 判漂移，经验值须自行重校） | 集合比对 |

**达标判定**：

- 计数在窄窗（±20%）内**往往不可达**（同向系统性低报，非随机）→ 计数**仅作同轮内参考**，跨轮以**区间**表述；
- **主判据改集合级**：核心位置重合率 ≥70% → 稳定 / 50–70% → 观察 / <50% → 判漂移（同尺、同族分类下）；
- BP-1/2/3/5/6 **保留**（有效且可机检）；**BP-4 降级为「报告下限」**（记录用，不作达标判据——硬下限在系统性低报下会**逼注水**）。

**锚定纪律**：参考值 / 下限只在**组织者侧**核对，**不得**写入审查员提示词或材料包（防「照着数字找」）。
**落点**：每次带预算的执行，输出须附「预算自检表」（BP 逐条 + 判定），结果记本规程 + `<校准台账>` changelog。

### 5.1.c 时间盒（执行节奏）

| 情形 | 可做 | 不可做 |
|---|---|---|
| **材料冻结期**（有指纹存档、正文不动） | 全量标定 / 漂移对质 / 双评 | — |
| **材料修改期**（正文未冻结） | 轻量审查（单轮快评、缺陷清单） | 标定 D₀ / 漂移判定（一边改一边量 = 不可归因） |
| **单轮上限** | 按 BP 预算执行 | 超预算未跑完却当「零发现」上报（须记「**未跑**」） |
| **积压** | 候选 / 残点逐条挂账 | 静默累计（连续 N 期未处理须在报告顶部标「⚠️ 积压」，N 为经验值） |

> **执行纪律**：本规程**只建机制、不跑校准**是允许的起点状态；一旦解禁，按 S1–S3（§5.1）与 BP 条款（§5.1.b）照单执行。

### 5.2 重校规程（每个阈值怎么被你自己的数据改掉）

| 阈值 | 重校方法 | 写入 |
|---|---|---|
| D₀（密度基准） | 对已知档位锚跑全量审查 → 算密度；同类型材料至少一批后再取定 | `<校准台账>` 锚行 + 本规程执行记录 |
| 倍数带宽（1× / 2×） | 用「已达标材料」与「已知不达标材料」的密度差分出可达区 | 同上（升版登记） |
| 漂移带（±20% / ±40%） | 同冻结样本、同组**双评**多次 → 统计差值分布，取「稳定 / 观察 / 漂移」分位 | 同上 |
| 重合率线（70% / 50%） | 同上，用核心位置集合算重合率；样本扩充前**禁止**称阈值「稳定常数」 | 同上 |
| 灵敏度门（70%） | 已知答案锚盲审 ≥2 轮 → 算覆盖率；漏重大问题即判不合格（不看总数） | 同上 |
| BP-4 系数（0.8） | 仅在无系统性低报的批次上标定；**宁可不设下限，不设逼注水的下限** | 同上 |

## 六、已否证路径（禁止重走）

> 下列做法在实测中被**否证**，列出以免重走；具体数值属校准者私有数据，此处只留**结论形态**。

| 路径 | 结论 | 理由形态 |
|---|---|---|
| 用**绝对计数**跨轮当 D₀/D₁ 基线 | **禁止** | 同向系统性低报：同材料同尺重评差异远超噪声，计数不可跨轮横比 |
| 把**硬密度下限**当达标判据 | **否证**（降级为报告下限） | 系统性低报下硬下限会**逼注水**（多报 / 拆分问题） |
| 用**正在修改中**的材料做漂移样 | **禁止** | 同时动尺与物 = 不可归因 |
| 单跑定论（不做双评） | **降级**：仅 <50% 漂移或争议件才升级双评 | 单跑深度受执行单元波动支配 |
| 换评审组比数 | **禁止** | 换组即换尺；跨组数字不可比 |
| 照搬其他赛道 / 其他领域的判准表与阈值 | **禁止** | 构念不同（覆盖率 vs 判档），照搬即伪精度 |
| 由被评样本自身数据提出阈值重构 | **不采纳**（除独立锚样本有增益） | 自证循环：用被评对象改尺必然「通过」 |
