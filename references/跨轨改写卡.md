# 多赛道改写卡（母版 → 目标赛道 · 勾选清单）

> **用途 / Purpose**：把「同一课题材料从一个赛道改写到另一个赛道」的**必做动作**做成可勾选、可留证的清单——数据引用不复制、匿名面按目标赛道重做、评审口径不串台、一稿多投禁令、重写而非复制、改写后过门禁。
> **版本 / Version**：v1.0（抽象版）。
> **模块指针**：多赛道改写模块（`VESI-ENGINE.md` §1 模块注册 · §3 门禁矩阵「跨轨」行 · §4 RB-V6）；赛道参数一律取**目标赛道的 track-config**（自建——本仓库不随附任何赛道参数）。
> **用法**：每完成一次跨赛道改写，**复制本卡**（落目标赛道侧或交接包），逐项勾选并留证；**任一项未勾 = 未过门禁**，不得交付。
> **纪律**：本卡只管**动作与门禁**；赛道参数（匿名要求、字数、格式）一律**只取目标赛道 track-config**，本卡不复写。
> **中性声明**：本产品不依赖任何特定 agent / CLI / 调度器。

---

## 0 · 使用前提（未满足则不得开跑）

- [ ] 目标赛道 **track-config 已读**（匿名 / 署名制、字数、模板、引用格式等参数以它为准）
- [ ] 母版已**冻结**：母版文件指纹（md5）+ 版本号已记（改写期间母版不动）
- [ ] 目标赛道**门禁清单**在手（匿名 / 格式 / 字数 / 引用格式，来源均指向目标赛道 track-config）
- [ ] 本次改写的**目标产物清单**已列（要哪几件：正文 / 摘要 / 图表 / 答辩口径）

---

## 1 · 数据单一正本（引用，不复制）

- [ ] 本次产物内**所有数字**均**引用**自数据唯一正本（`kb/`），未在目标赛道目录内新建平行数据表 / 副本
- [ ] 产物中每个数字都能指回正本的条目名（口径字典：`references/数据条目字典.md`）
- [ ] 未出现「从母版表格复制过来」的裸数字（复制即产生**双正本**风险）
- [ ] 若确需赛道侧派生值：已在产物内标 `inference` 并记 `derived_from`（公式 + 参数），未改动正本
- [ ] 数据口径（单位 / 基准 / 累积口径）与母版**逐条对齐**；如目标赛道要求换口径，已换并留痕（不静默重算）

## 2 · 匿名面按目标赛道重做

- [ ] **匿名制赛道**：按目标赛道 track-config 的匿名条款执行**三层扫描**（正文 / 图表字面 · 文档属性 / 元数据 · 附件与嵌入对象；层清单以 track-config 为准）
- [ ] **署名制赛道**：按目标赛道要求**回填**署名、单位、指导教师等信息，位置与格式符合该赛道模板
- [ ] 匿名 / 署名**不跨赛道沿用**：未把上一赛道的匿名版直接当署名版用，也未把署名版剪贴成匿名版（须**重做**该面）
- [ ] 扫描证据已留（扫描范围 + 命中 + 处置 + 时间戳）
- [ ] 文件级元数据已核（作者名 / 机构 / 计算机名等不进产物）

## 3 · 评审口径不串台

- [ ] 目标赛道的**评分 / 判档标准、术语口径、格式要求**只取目标赛道 track-config；未沿用来源赛道的评分表、禁词表、术语偏好
- [ ] 来源赛道的**评审结论 / 分数 / 档位 / 缺陷清单**未写入目标赛道材料、答辩口径或摘要
- [ ] 未把「为 A 赛道评委写的话术」原样搬进 B 赛道（各赛道关注点不同，须按 §5 重写）
- [ ] 目标赛道禁止事项已核（禁词 / 禁用图型 / 禁用表述，以 track-config 为准）

## 4 · 一稿多投禁令

- [ ] 同一材料**整体**未同时投递 / 上传到两个赛道或期刊
- [ ] 若已投递 A 赛道而需出 B 赛道件：B 赛道件按 §5 **重写**（非复用），并确认两赛道赛事章程对「同一课题重复投递」的规定已核
- [ ] 若目标赛道对「初赛稿 / 决赛稿」「会议稿 / 期刊稿」有复用规则：已按**官方章程**判定（不以经验代替查章程）
- [ ] 本次交付的用途与投递对象已写明（避免无意重复投递）

## 5 · 表述 / 结构 / 侧重重写（而非复制）

- [ ] **结构**按目标赛道大纲重排（不是删段落）
- [ ] **侧重点**按目标赛道评审关注点调整（研究性 ↔ 计划性 ↔ 应用性 面不同）
- [ ] **表述**逐处重写：标题、摘要、图选择与图注、结论措辞，均非机械同义替换
- [ ] 未出现母版**整段**照搬（逐段对质：可有事实与数字相同，不可有段落复制）
- [ ] 引用表按目标赛道引用格式**重建**（指针 `references/引用格式卡.md`），未直接搬运母版编号
- [ ] 图表：按目标赛道要求重选（保留哪些、合并哪些、是否需要新图），图注重写并自含

## 6 · 改写后门禁（全部过完才算完成）

- [ ] 过 `VESI-ENGINE.md` §3 **「跨轨」行**：改写卡勾选**全过** + 留证
- [ ] 目标赛道格式门禁已过（模板 / 字体 / 页边距 / 字数，以 track-config 为准）
- [ ] 匿名面门禁已过（匿名制赛道：三层扫描全过；署名制赛道：署名 / 单位回填完整）
- [ ] 数据面门禁已过（§1 全部勾选；数字可回溯）
- [ ] 目标赛道若有 docx 交付：过 `scripts/assert_delivery_hygiene.py`，FAIL=0（指针与用法见 `references/论文装配SOP.md` §4）
- [ ] 指针可解析：产物内所有路径 / 引用在目标赛道侧**实际打得开**（不残留来源赛道目录的指针）
