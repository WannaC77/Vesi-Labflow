# 行为测试 · 最小自检清单（v1.0 · 抽象版）

> 定位：**最小行为自检清单**——**行为层最小集**（交付前 5 分钟可过）；与「完整合规门禁清单」分工不同、不互相替代。
> **中性声明**：本产品不依赖任何特定 agent / CLI / 调度器。

## 一、触发条件（满足任一即跑）

1. 任何**正式交付物**（申报书 / 中期报告 / 结题材料 / 论文 / 答辩稿）**定稿或提交前**；
2. 跨文档口径发生变更后（术语 / 数字 / 单位在 ≥2 份材料间动过）；
3. 整改批次落盘后（P0/P1 修复完成的那一批）。

## 二、最小项（8 条 · 逐条留痕，无痕 = 未跑）

| # | 测试项（行为 = 看输出，不看声明） | 通过线 | 留痕 |
|---|---|---|---|
| B1 | **溯源**：每个数据性结论给出来源（文献→PMID/DOI；实验数据→文件路径+日期；统计→检验名+统计量+p+效应量） | 抽 3 条，条条可追 | 抽查记录 3 行 |
| B2 | **跨文档口径**：同一数字 / 术语在（申报书 / 设计 / 论文）三处一致 | 抽 3 处全一致 | 对账表（数字→材料×3） |
| B3 | **数字复算**：≥3 个承重数字可独立复算（含单位换算） | 3/3 对上 | 复算式 |
| B4 | **匿名 / 署名按目标赛道判定**：以目标赛道 track-config 为准（匿名制 → 走三层扫描；署名制 → 回填署名，匿名条目**不适用**） | 赛道规则核过 | 一行判定 |
| B5 | **格式对标按目标赛道**：以目标赛道官方格式 / 模板为准（**其他赛道的字数与页数条款不得套用**） | 官方格式核对单过 | 核对单 |
| B6 | **引用规范**：行内标注与文献表一一对应、格式统一 | 零错位 | 引用序扫描输出 |
| B7 | **失败 / 异常如实**：不利数据 / 未收敛 / 异常结果在文中如实报告（不美化、不删除——红旗前兆检查） | 无美化痕迹 | 自查一行 |
| B8 | **交付件卫生**：字面标记（`**` 等）0 残留、元数据干净、版本号 / 日期正确 | 0 命中 | 扫描输出 |

> 5 分钟打法：B2/B3/B6 用「数字对账」一次扫完；B4/B5 是**判断题**（看目标赛道配置即答）；B7/B8 肉眼 + 脚本各一次。

## 三、赛道条款不跨用（防错借）

| 条款类型 | 判定 |
|---|---|
| 查重预检 | ✅ 通用——原创性声明是各赛道共同要求 |
| 论文 - 记录一致性 | ✅ 通用——数据单一正本（`kb/`） |
| 跨文档口径 | ✅ 通用——与本清单 B2 同 |
| 匿名化（校名 / 姓名 / 照片 / 元数据） | ⚠️ **按赛道**：匿名制赛道适用；署名制赛道**不适用**（勿反向匿名化） |
| 字数 / 页数上限 | ⚠️ **按赛道**：只取目标赛道官方文件——**不得把 A 赛道的页数条款套到 B 赛道** |
| 记录锁定时间 / 篇数上限 | ⚠️ **按赛道**：仅在该赛道章程明写时适用；内部日志无此约束 |
| 本地工具链 | ✅ 通用：交付件卫生 `scripts/assert_delivery_hygiene.py`、引用编号 `scripts/ref_numberizer.py`、口径核验 `scripts/consistency_check.py`（清单见 `scripts/README.md`） |

## 四、执行记录格式（一行式）

```
[YYYY-MM-DD][触发: 交付前/口径变更/整改批] B1✓(抽查3) B2✓(3处) B3✓(3数) B4=署名制-不适用 B5✓ B6✓(0错位) B7✓ B8✓ | 未通过项 → 缺陷清单编号
```

## 五、边界

- **不是评分**：本清单判「做没做」，不判「好不好」；质量由评审族（审稿人 / 模拟评审）负责。
- **禁止假装**：逐项留痕，无痕 = 未跑；需要完整行为测试体系时另立清单（保留路线图）。
- 与**实验记录**检查点不重叠：后者管实验记录，本清单管**交付物**。
