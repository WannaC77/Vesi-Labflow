# 冷水证据（否证方法与登记规范）

> **用途 / Purpose**：交付前**主动找否证**——把「这条结论可能不成立」的反例、反证与边界条件集中登记，与支持证据**同权呈现**；本卡是冷水条目的**登记规范 + 方法卡**，不含任何课题专用文献清单。
> **版本 / Version**：v1.0（公开版）｜模块指针：V-M1 文献 LIT · V-M6 图件车间 · V-M7 论文装配（`VESI-ENGINE.md` §1）
> **纪律（两条）**：① 冷水条目必须带**可核验出处**（标识符 / DOI / 可复现数据或教科书级共识），无出处的怀疑不入卡；② **平衡呈现**——只列冷水不列支持证据，与只列支持证据不列冷水一样，都是不合格的论述。

---

## 1 · 什么是「冷水」

冷水 = 你在交付前**对自己结论提出的否证**：`如果这条结论是错的，最可能错在哪？` 它有三个动作：

| 动作 | 问句 | 产出 |
|---|---|---|
| **找否证** | 有没有证据**反对**这个结论？（阴性结果、失败案例、争议综述、重复性报告） | 否证条目（带出处） |
| **找反例** | 有没有**同类研究得出相反结论**？差在条件还是差在方法？ | 条件差异表（变量 / 体系 / 检测口径） |
| **找边界** | 这个结论**在什么范围内**成立？（模型 / 剂量 / 时间窗 / 体外-体内） | 结论的适用范围与禁止外推项 |

**时机**：设计定稿前（约束方案）、数据解读时（约束解释）、论文与答辩前（约束表述）。冷水不是「自我否定」，而是把结论的**适用边界写清楚**——答辩与评审最常追问的正是这里。

## 2 · 冷水三层次（通用框架）

三层次从「体系」到「机制」到「方法」，逐层收紧结论的可用范围。下列示例均为**公开领域通用例子**（不含具体文献标题与条目号），替换为你自己的体系时保持层次不变。

### 层次一 · 体系层：受试体系在真实环境中的行为可能偏离设计预期

- **冷水内容（通用）**：纳米尺度的载体进入生物体液后，会被血浆蛋白吸附形成**蛋白冠**，从而改变其表面性质、粒径与体内命运；表面修饰（如亲水长链）可减缓但不能完全阻止这一过程。
- **通用示例**：体外缓冲液中的粒径与释放曲线，不能直接等同于入血后的粒径与释放行为——测的是两个不同的体系。
- **对本研究的约束**：体内行为（循环时间 / 组织蓄积 / 释放）可能偏离处方设计预期；器官蓄积的解读必须考虑**单核-巨噬细胞系统摄取**这一替代解释（主要蓄积器官的富集是**预期行为**，不宜直接叙述为「靶向成功」）。
- **自查问句**：我有没有把「体外表征结果」直接写成「体内行为」？

### 层次二 · 机制层：机制解释存在公开争议或外推缺口

- **冷水内容（通用）**：常见的高通透长滞留（EPR）类机制在**动物肿瘤模型**中被广泛使用，但其在**人体肿瘤**中的临床相关性存在公开争议；不同研究报告的肿瘤蓄积比例差异很大，且普遍不高。
- **通用示例**：动物模型上的「靶部位蓄积倍数提高」，不能直接换算为「临床获益」；建立机制主张需要独立证据（影像 / 药效 / 暴露-效应关系），而不是单一分布数据。
- **对本研究的约束**：不设肿瘤模型的体系不存在「靶向肿瘤」命题；机制类叙述须降级为**待验证机制**并标 `[假设]`，不得写成既定事实。
- **自查问句**：我的机制主张，除了这一个数据点，还有别的独立证据吗？

### 层次三 · 方法层：测定方法决定结论边界

- **冷水内容（通用）**：当受试物存在**载体结合态与游离态**之分时，只测总量只能回答「总浓度不同」，回答不了「释放不同」；要比较释放行为，必须做**结合态 / 游离态的分离测定**（如固相萃取、超滤离心），而**分离方法自身即引入不确定度**（回收率、吸附损失、解离平衡移动）。
- **通用示例**：体外释放曲线与体内释放行为之间没有可直接套用的换算关系（介质、酶、pH、剪切条件都不同）。
- **对本研究的约束**：任何「体内释放更优」的结论，都必须建立在分离测定的方法学之上，并在报告中声明分离方法、回收率与质控结果；否则结论只能写「药代行为不同」。
- **自查问句**：我的检测口径，能支撑我写下的那个结论吗？

## 3 · 找否证的操作步骤

1. **列主张**：把准备写进论文 / 报告 / 答辩的结论句逐条抄出来（一句一行）。
2. **逐条反查**：对每条主张，用「反对词」检索一遍——阴性 / 失败 / 争议 / 重复性 / 局限 / 不一致等词面 + 体系关键词；并优先读**综述的局限段**与**同类研究的结论差异段**。
3. **核对条件**：找到反证后，先比条件再下判断——对象（物种 / 模型）、剂量与暴露、时间窗、检测口径、样本量；条件不同 ≠ 结论被推翻，但**必须写明差异**。
4. **登记**：按 §4 格式登记，注明「对本研究的约束」。
5. **回写**：约束落到三处——设计卡（前置约束）、分析报告（解读边界）、论文 / 答辩稿（表述与局限段）。
6. **复核周期**：每季度重检索一次，更新时**逐条重新核实出处**（见 §5）。

> 反例的价值高于赞同证据：**找不到反例**不等于结论坚不可摧，只等于「本次检索未命中」，须在报告中如实写这一句。

## 4 · 冷水条目登记格式（模板）

```markdown
### 冷水 N · <层次：体系 / 机制 / 方法> · <一句话命题>
- **冷水**：<否证命题，一句话；不带情绪词>
- **出处**：<标识符（PMID / DOI）或「教科书级共识：<教材/领域共识来源>」>；核实日期 <YYYY-MM-DD>
- **通用示例**：<公开领域示例，用于说明该否证在同类体系中的表现>
- **对本研究的约束**：<结论要降级成什么 / 要补什么证据 / 禁止哪种外推>
- **三态**：<[事实] / [推断] / [假设]>
- **状态**：<已并入 <设计卡 / 报告 / 论文局限段>  |  待补证据  |  已过期待复核>
```

**三层次齐备检查**（交付前逐项打勾）：体系层 □ · 机制层 □ · 方法层 □ —— 三层不必都有条目，但**缺失的层要写明「本体系为何不适用」**，不得静默略过。

## 5 · 使用规范与核实方法

**使用规范**

1. 论述受试物的体内行为 / 分布 / 释放时，必须**同时**给出冷水与支持证据，并各自带出处；
2. 每条冷水引用必须带标识符（PMID / DOI）或明确的领域共识来源；**未收录 / 未核实的文献，先实证再引用**；
3. 不得用「有研究认为」这类无出处句式替代具体引用；
4. 每季度检索一次新证据并更新本卡，更新时逐条重新实证。

**核实方法（元数据实证）**：搜索引擎摘要**只作线索**，作者 / 年份 / 期刊 / 标识符一律以官方接口或原文页为准：

```text
esummary: https://eutils.ncbi.nlm.nih.gov/entrez/eutils/esummary.fcgi?db=pubmed&id=<PMID>&retmode=json
esearch（按标题精确）: .../esearch.fcgi?db=pubmed&term=%22<标题>%22[Title]&retmode=json
```

> **历史教训（机制，不涉个案）**：本卡曾出现过**整批标识符为编造、抽查全部与主题无关**的事故；根因是「用搜索摘要的作者与序号直接入卡」，未做逐条实证。此后纪律为：**标识符逐条过接口、作者归属逐条核对原文页、核不到就标 `[待核]` 而不是先写进去**。
