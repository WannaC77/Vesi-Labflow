# 引用格式卡（数字顺序制 · Vancouver 风格速查）

> **用途 / Purpose**：写论文/申报书时**取用即抄**的引用格式速查——文内标注、期刊名缩写、常见条目类型模板、待定项登记。
> **版本 / Version**：v1.0（2026-09-21 · 生成侧强化批 3 · V-M7）
> **模块指针**：V-M7 论文装配 PAPER（装配流程见 `references/论文装配SOP.md` §5）
> **口径状态**：**`[待定：按目标期刊 / 赛事要求]`** —— 未定前**默认数字顺序制（Vancouver 风格）**；一旦目标格式确定，改本卡头部口径并填 §5 对照表。
> **纪律（三条）**：
> 1. **元数据必须实证**：作者/年份/期刊/卷期页/DOI/PMID 逐条过 NCBI esummary 或出版物原件；**禁止凭记忆或搜索摘要填**（对齐 `workflows/08-数据处理与可视化.md` §LS-8-5）。
> 2. **示例一律占位**：本卡所有示例用 `<占位>`，**不得**把示例当真实文献抄进产物。
> 3. **格式未定不混用**：同一交付件内不得混排两种体例（数字顺序制 + 著者-年份制）。

## 1 · 文内标注（数字顺序制）

| 情形 | 写法 | 说明 |
|---|---|---|
| 单篇 | `…结论[1]。` | 标点**在括号外**（按目标格式复核；部分期刊要求 `[1].`） |
| 两篇不连续 | `…[1,2]` | 逗号无空格 |
| 连续三篇及以上 | `…[1-3]` | 连字符用半角 `-` |
| 多篇混合 | `…[1,3-5]` | 升序排列，不写降序 |
| 句中引用（作者作主语） | `Smith 等[1]报道…` | 姓名写正文、编号写方括号 |
| 图/表来源 | `图注末尾：数据来源[1,2]。` | 图注内也要标，不允许「见正文引用」 |

**编号规则**：编号按**文内首次出现顺序**分配（顺序编码制），文末列表**同序排列**；**增删引用后必须全表重编号**（不得留空号/跳号）。

## 2 · 期刊名缩写说明

| 规则 | 做法 |
|---|---|
| 缩写标准 | 采用 **NLM 标准缩写**（PubMed 记录口径） |
| 取法 | 以 PubMed 记录中的**期刊缩写字段**为准（esummary 输出的刊名缩写与全称两字段，字段名以当前 NCBI 输出为准）；无缩写记录时写**全称** |
| 禁止 | 不得自造缩写、不得凭印象缩写、不得混用「缩写 + 全称」（同一刊名全文统一） |
| 核对动作 | 每条文献：题名 → 期刊缩写 → 卷期页 → DOI/PMID **四项齐全**才算入库 |
| 中文期刊 | 写中文全称（按目标格式；需英文者按期刊官方英译名） |
| 标点 | 缩写词尾**不加**句点（NLM 风格，按目标格式复核） |

## 3 · 条目模板（数字顺序制 · 骨架）

> 全部使用 `<占位>`；斜体/加粗等排版按目标格式套用，本卡只定**元素与顺序**。

### 3.1 期刊文章（最常用）

```text
<Author1> <Initials>, <Author2> <Initials>, <Author3> <Initials>, et al. <Article title>. <Journal abbrev>. <Year>;<Volume>(<Issue>):<StartPage>-<EndPage>. doi:<DOI>.
```

| 元素 | 要求 |
|---|---|
| 作者 | 姓 + 名缩写（缩写无点、无空格）；数量阈值与 `et al.` 触发按目标格式（默认 >6 取前 6 + et al.） |
| 题名 | 句首大写（sentence case），不加引号，**句末加句点** |
| 期刊 | NLM 缩写（§2）；句末句点 |
| 年;卷(期):页 | `2026;12(3):45-52`；无期号可省 `()`；电子优先出版写 `doi:` |
| DOI | 有则必填，形如 `doi:10.xxxx/xxxxx`（**不写** `https://doi.org/`，按目标格式复核） |
| PMID | 一般不写入条目；本课题在证据表中另栏记录以便复核 |

### 3.2 专著（整本）

```text
<Author(s)>.<Book title>. <Edition>. <Place of publication>: <Publisher>; <Year>. p. <Pages>.
```

### 3.3 专著章节 / 会议论文集章节

```text
<Chapter author(s)>. <Chapter title>. In: <Editor(s)>, editors. <Book title>. <Edition>. <Place>: <Publisher>; <Year>. p. <StartPage>-<EndPage>.
```

### 3.4 网页 / 在线资源

```text
<Author or Organization>. <Page title> [Internet]. <Place>: <Publisher>; <Year> [updated <YYYY-MM-DD>; cited <YYYY-MM-DD>]. Available from: <URL>
```

| 元素 | 要求 |
|---|---|
| 责任者 | 无个人作者写机构名（与网站名不同时两者都写） |
| `[Internet]` | 媒介标记，方括号 |
| 更新/引用日 | `[updated …; cited …]`；**引用日期必填**（网页可变） |
| URL | 完整可解析；不得写短链 |
| 存档 | 关键网页应留本地存档（快照/PDF）并记入证据表，防链接失效 |

### 3.5 标准 / 规范

```text
<标准号> <标准名称> [S]. <发布机构>: <发布地>, <发布年>.
```

| 元素 | 要求 |
|---|---|
| 标准号 | 完整编号（如 `GB/T <编号>-<年>` / `ISO <编号>:<年>`） |
| `[S]` | 文献类型标识（标准）；其他类型标识按目标格式（`[J]` 期刊 / `[M]` 专著 / `[EB/OL]` 网络资源 等） |
| 状态 | 已废止/被替代的标准须注明（并优先引现行版） |

## 4 · 装配期速查（引文相关的常见坑）

| 坑 | 处置 |
|---|---|
| 作者归属错（搜索摘要给错） | 一切以 esummary / 出版物原件为准（§纪律 1） |
| 刊名缩写不一致（同刊两种写法） | 全文统一为 PubMed 缩写；改一处须全库复查 |
| 编号不连续（删引用后未重排） | 全表重编号 + 文内 `[n]` 机械对质（脚本计数，不目视） |
| 列表有未引条目 / 文内有孤号 | 文内 ↔ 列表**双向集合差**须为空 |
| 二手引用（转引未读原文） | 不写转引；读原文并按原文核元数据（读不到则降级表述或删除） |
| 网络资源失效 | 引前即存档（§3.4 存档行） |
