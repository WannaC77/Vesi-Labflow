# MODULE · V-M1 文献（LIT）

> 所属：`modules/V-M1-文献/`｜层：L0｜版本：v1.0（2026-09-21）｜引擎：`VESI-ENGINE.md` §1

## 目的 / Purpose
检索 → 精读 → 证据表：把文献转成可溯源、带三态标注的证据资产。

## 输入 → 输出 / IO
- 输入：检索主题/关键词；上游无（模块起点）
- 输出：精读笔记 / 证据表 / 检索记录（三件）

## 接口字段 / Interface
精读笔记：题录（PMID/DOI/期刊/年）/目的/方法/关键数据/结论局限/三态/启示；证据表：论断句|证据类型|来源|三态|强度|备注。模板见 `templates/精读笔记模板.md`、`证据表模板.md`。

## 装载 / Loading（指针，细节在正本）
`workflows/02-文献调研.md`（正本）；`templates/精读笔记模板.md`、`templates/证据表模板.md`；`references/检索式库.md`

## 门禁 / Gates
元数据可核验（PMID/DOI 直链核对）；三态标注齐；检索式可复跑（登记命中数与日期）

## 降级 / Fallback
无文献类技能机制 → E-utilities/数据库网页手工检索 + 笔记内标 `[降级]`

## 样例 / Example（合成或去敏）
合成示例：任选 1 条 PubMed 记录走一遍模板（示例数据仅作格式演示，不入库）
