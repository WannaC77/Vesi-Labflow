# MODULE · V-M3 记录线（RECORD）

> 所属：`modules/V-M3-记录线/`｜层：L0｜版本：v1.0（2026-09-21）｜引擎：`VESI-ENGINE.md` §1

## 目的 / Purpose
照片/口述/原始文件 → 结构化实验记录（字段全），原始数据只读归档。

## 输入 → 输出 / IO
- 输入：原始文件（照片/表格/仪器读数）+ 设计卡（V-M2）
- 输出：结构化实验记录（字段全）+ 原始文件归档索引

## 接口字段 / Interface
实验记录字段：日期/实验项/目的/人员｜材料与批次｜操作步骤（实际）｜原始数据文件路径（只读）｜观察与异常｜结论与下一步｜执行者。模板：`templates/实验记录模板.md`；条目命名与口径：`references/数据条目字典.md`。

## 装载 / Loading（指针，细节在正本）
`workflows/12-实验执行与排障.md`（正本）；`scripts/transcribe_record.py`（口述转写）；`templates/实验记录模板.md`；`references/数据条目字典.md`

## 门禁 / Gates
字段齐；原始数据不可改（只读归档）；记录↔文件路径一一对应；条目命名遵循字典

## 降级 / Fallback
口述+代录，标注执行者与转写工具；无转写脚本则手工录入并复核

## 样例 / Example（合成或去敏）
合成记录示例：3 行表头 + 1 行合成占位数据（仅演示格式）
