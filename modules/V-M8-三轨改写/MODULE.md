## 目的 / Purpose
母版 → 目标轨材料：匿名/口径/结构按目标轨重做（指针，不复制正文）。

## 输入 → 输出 / IO
- 输入：母版材料（数据正本在 KB）
- 输出：目标轨材料 + 改写卡勾选记录

## 接口字段 / Interface

## 装载 / Loading（指针，细节在正本）
`track-config.md`、`track-config.md`（轨侧正本）；`VESI-CORE.md` 轨道节（L1）

## 门禁 / Gates

## 降级 / Fallback
无匿名脚本 → 手工三层扫描清单勾选；口径核对走 track-config 对应节
