# MODULE · V-M11 编排器（ORCH）

> 所属：`modules/V-M11-编排器/`｜层：L0｜版本：v1.0（2026-09-21）｜引擎：`VESI-ENGINE.md` §1

## 目的 / Purpose
runbook 编排与交接卡：把模块串成线（RB-V1–V6），每交付记一次交接。

## 输入 → 输出 / IO
- 输入：主线任务（申报/方案/数据/论文/答辩/跨轨）
- 输出：交接卡（输入/产物/门禁/降级/下一步）

## 接口字段 / Interface
交接卡字段：日期·模块｜输入（上游产物+路径）｜产物（路径+版本）｜门禁（过哪条+留证）｜降级/未决｜下一步。

## 装载 / Loading（指针，细节在正本）
`VESI-ENGINE.md` §4（RB-V1–V6）与 §7（交接卡模板）

## 门禁 / Gates
每交付一次交接记录；runbook 选线明确（不混线）

## 降级 / Fallback
口述交接 + 文字记录（尽量入卡）

## 样例 / Example（合成或去敏）
交接卡示例（合成）：M4 报告 → M6 图 → RB-V4 下一步
