# kb/ — 你的私有知识库（自建目录）

本目录是**空位**：仓库不附带任何文献全文、他人材料或官方文件（版权与合规原因）。
请在这里放**你合法持有**的内容，并让它服务你的研究流程。

## 建议结构

```
kb/
├── topics/         # 领域主题页（每个主题一页：背景 / 关键文献 / 未解问题）
├── methods/        # 方法笔记（统计 / 药代 / 释放 / 表征 / 分子与细胞实验）
├── notes/          # 复盘笔记、失败记录、可复用片段
└── index.md        # 目录索引（一页看全，便于渐进加载）
```

## 使用约定的三条

1. **来源标注**：每条材料写清来源（公开链接 / 自撰 / 授权范围）。未标注的不要入库。
2. **三态标注**：结论标 `[事实] / [推断] / [假设]`——尤其从文献推出的机制。
3. **一页索引**：`index.md` 只放指针与一句话摘要；正文分文件，避免单文件过大。

## 与工作流的关系

| 场景 | 入口 |
|---|---|
| 文献调研与证据表 | `workflows/02-文献调研.md` → 在 `kb/topics/` 建主题页 |
| 实验设计与记录 | `workflows/03-制剂制备与表征.md` · `workflows/12-实验执行与排障.md` |
| 统计与出图 | `workflows/08-数据处理与可视化.md` → `kb/methods/` 记口径 |
| 复盘归档 | `workflows/11-知识管理.md`（含**提炼机制**：候选 → 复核 → 落盘） |

> 目录内容默认不入 git（见根目录 `.gitignore`：`kb/*` 已被忽略）。
> 想版本化自己的知识库，请另建私有仓库，不要提交到这里。
