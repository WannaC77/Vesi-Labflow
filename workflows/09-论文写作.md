# 09 — 论文写作工作流

> 触发：论文、写作、摘要、introduction、discussion、投稿、期刊
> 注：**申报书**的写作以 `templates/申报书线/申报书写作工作流.md` 为正本（含四维框架与得分点对标），本工作流只提供通用学术写作规范；目标赛道方法论另见 grant-proposal-cn skill。

---

## 写作顺序

```
Methods → Results → Introduction → Discussion → Abstract → Title
```

理由：Methods和Results是客观描述，最容易写；Introduction和Discussion需要全局视角，放后面写更准确。

---

## IMRaD 结构

### Methods（最先写）

#### 制剂制备
- 脂质组成：名称、比例、厂家、纯度
- 制备方法：薄膜水化-挤出法（每步参数精确）
- 载药方法：硫酸铵梯度法（浓度/温度/时间）
- 透析条件：MWCO/时间/温度/换液次数
- 除菌过滤：0.22μm滤膜

#### 制剂表征
- 粒径/PDI：DLS仪器型号、稀释条件、测量次数
- Zeta电位：仪器、介质条件
- 形态：TEM/Cryo-TEM（制备方法、染色条件）
- 包封率：测定方法（凝胶过滤/超滤）、HPLC条件

#### 体外释放
- 释放方法：透析袋法（MWCO/体积比/温度/振荡速度）
- 释放介质：组成/pH/体积
- 采样时间点
- 药物测定：HPLC条件

#### 体内PK实验
- 动物：品系/性别/体重/周龄/来源/伦理审批号
- 分组：脂质体组 vs 参比制剂组（n=?）
- 给药：途径/剂量/体积/速度
- 采血：方法/时间点/抗凝剂
- 血浆处理：离心条件/储存条件
- LC-MS/MS：色谱柱/流动相/梯度/质谱条件/内标/方法验证

#### 组织分布
- 取材时间点
- 取材组织
- 组织处理：匀浆方法/提取方法/内标
- 检测：LC-MS/MS条件

#### 排泄实验
- 胆管插管：方法
- 代谢笼：型号
- 收集时间点
- 样品处理

#### 统计方法
- 软件（GraphPad/Python/Phoenix WinNonlin）
- 具体检验方法
- 显著性标准（p<0.05）
- PK参数计算方法（NCA/房室模型）

- **可复现性测试**: 别人读了Methods能重复你的实验

### Results（第二写）

#### 推荐结构
1. 制剂表征结果（粒径/PDI/Zeta/EE%/形态/稳定性/批间一致性）
2. 体外释放结果（释放曲线/释放动力学/模型拟合）
3. 体内PK结果（血药浓度曲线/PK参数/相对生物利用度）
4. 组织分布结果（各组织药物浓度/热图/靶向效率）
5. 排泄结果（胆汁/尿液/粪便排泄率/代谢物）

- 每段：描述数据 → 统计结果 → 小结论
- 图表引用：先描述数据，再"as shown in Figure X"
- 不解释不讨论（留给Discussion）
- **数据叙事**: 每个Figure讲一个故事，串联起来讲完整故事

### Introduction（第三写）

- **倒三角结构**:
  1. 大背景（候选药物 X在肿瘤治疗中的地位+局限性）
  2. 具问题（参比制剂剂型的PK/毒性问题）
  3. 已有方案及局限（现有脂质体制剂研究进展）
  4. 本工作的创新方案（我们的脂质体处方设计）
  5. 一句话总结核心发现
- 引用：近5年≥60%，覆盖领域关键文献
- 最后一段：明确说"In this study, we..."

### Discussion（第四写）

- **结构**:
  1. 重申核心发现（1段）
  2. 与文献比较（脂质体PK特征与已报道数据比较）（2-3段）
  3. 机制解释（为什么脂质体改变了PK/分布/排泄）（1-2段）
  4. **局限性**（诚实，1段）
  5. 未来方向（1段）
  6. 结论（1段，与Abstract呼应）
- **铁律**: 不过度解读，不超出数据范围

### Abstract（最后写）
- 背景（1-2句）→ 目的（1句）→ 方法（2-3句）→ 结果（2-3句，含关键数据）→ 结论（1-2句）
- 字数：250词（看期刊要求）
- 不引用文献，不用缩写（首次出现除外）

### Title
- 准确、简洁、信息量大
- 包含关键词（候选药物 X、脂质体、药代动力学、组织分布、排泄）
- 避免"novel""first""new"等空泛词

## 英文学术写作要点

| 要点 | 常见错误 | 正确做法 |
|------|---------|---------|
| 时态 | 全用过去时 | Methods/Results用过去时，Discussion普遍规律用现在时 |
| 语态 | 全用被动 | Methods可用被动，Introduction/Discussion适当用主动 |
| 用词 | "got""a lot of" | "obtained""significant/substantial" |
| 句子 | 长句套从句 | 一句一个意思，≤25词/句 |
| 连接 | 缺逻辑连接词 | "However""Moreover""In contrast""Notably" |
| 数字 | 句首用数字 | 句首拼写（"Three..."），文中用阿拉伯数字 |

## 投稿策略

### 期刊选择
根据工作水平和内容匹配：
- **高水平**: European Journal of Pharmaceutics and Biopharmaceutics, International Journal of Pharmaceutics, Drug Delivery
- **中等**: Pharmaceutics, AAPS PharmSciTech, Journal of Liposome Research
- **保底**: 与领域相关的SCI期刊

### 投稿前
- [ ] 查重（iThenticate/Turnitin，<15%）
- [ ] 格式符合目标期刊（Author Guidelines）
- [ ] Cover Letter准备好
- [ ] Highlights准备好（3-5条）
- [ ] Graphical Abstract准备好
- [ ] 所有作者确认署名顺序
- [ ] 原始数据备份完成
- [ ] 已核对目标期刊/学校的 AI 使用政策，AI 辅助程度已按要求声明
- [ ] 全文已由本人逐句重写关键论述（AI 生成文本不直接署名提交）

### Cover Letter 三段式
1. 我们做了什么（一句话核心发现）
2. 为什么重要（解决什么问题，创新在哪）
3. 为什么适合这个期刊（与期刊scope匹配）

## 论文 Checklist

- [ ] 逻辑链自洽（问题→方法→结果→结论无断裂）
- [ ] 数据叙事有说服力
- [ ] 引用充分且准确（证据等级适当）
- [ ] 图表规范（误差棒/n/显著性/单位）
- [ ] 英文表达准确
- [ ] 讨论诚实（局限性提及，不过度解读）
- [ ] 数值有单位，有效数字正确
- [ ] PK参数完整（AUC/Cmax/t1/2/MRT/CL/Vd/Frel）
- [ ] 参考文献格式统一
- [ ] 缩写首次出现有全称

## 迭代循环（稿件打磨）

AI 初稿 → 自查 checklist → 修改 → 审稿人模式审查 → 人用自己话重写 → 定稿
 ↑ 最多 3 轮 ←──────────────────────────────────────────────────────────┘

每轮重点：第 1 轮结构和逻辑 → 第 2 轮数据和引用 → 第 3 轮语言和风格
