# 10 — 答辩准备工作流

> 触发：答辩、PPT、Q&A、汇报、展示、结题、中期检查

---

## 答辩故事线（10分钟版）

```
① 问题（1min）
   "候选药物 X 参比制剂的临床局限？为什么需要脂质体制剂？"
    ↓
② 方案（1min）
   "我们做了什么？脂质体处方设计思路？"
    ↓
③ 数据（5min）
   制剂表征 → 体外释放 → PK比较 → 组织分布 → 排泄特征
   最有说服力的2-3个数据重点讲
    ↓
④ 结论（1min）
   一句话总结：脂质体如何改变了候选药物 X 的体内行为
    ↓
⑤ 展望（30s）
   下一步打算做什么（药效？毒理？临床前？）
```

## PPT设计原则

### 视觉规范
- 每页一个核心信息，不堆砌
- 字体：标题≥32pt，正文≥24pt，注释≥18pt
- 图表占页面≥60%
- 配色统一（2-3种主色），不花哨
- 无动画/极简动画（fade即可）
- 白底深字或深底浅字，保持一致

### 图表突出
- 关键数据放大突出
- 非关键信息淡化（灰色/小字）
- 误差棒、n、p值必须有
- 最重要的Figure放最显眼位置

### 时间控制
- 每页分配时间，写在备注里
- 练习时按80%时长训练（留余量）
- 数据页可能讲久，预留弹性

## Q&A 高频问题

### 必问题
1. 你的创新点是什么？与已有候选药物 X 脂质体制剂相比优势在哪？
2. 为什么选择这个脂质组成/比例？考虑过其他方案吗？
3. 体外释放结果能代表体内释放行为吗？
4. 脂质体为什么能延长半衰期？机制是什么？
5. 组织分布数据显示肝脏蓄积增加，这是好事还是坏事？
6. 排泄实验显示胆汁排泄为主，这与参比制剂有什么不同？
7. 你的实验可重复性如何？做了几次独立重复？
8. 这个研究的局限性是什么？

### 进阶问题
9. 如果继续做下去，下一步打算做什么？（药效学？毒理？临床前？）
10. 这个方案的临床转化前景如何？
11. 成本效益如何？比现有参比制剂贵多少？
12. 你的统计数据为什么用这个检验方法？
13. 为什么用这个动物模型？与其他模型相比优劣？
14. <活性代谢物>的活性比候选药物 X 高，脂质体对<活性代谢物>生成有什么影响？
15. 脂质体在体内会与血浆蛋白结合形成蛋白冠，你考虑过吗？

### 回答策略
- **30秒精炼回答**：先一句话结论，再展开
- **不确定时诚实说**："这个问题我目前没有确切数据，但基于文献..."
- **被质疑时**：不防御，用数据回应
- **不会的问题**："这是一个很好的问题，我目前没有考虑过，后续研究中..."

## 成果展示策略

**原则**: 精致而非炫耀，让数据自己说话

### 卖点提炼
每个阶段问自己：**"如果只能告诉评审人一件事，说什么？"**
- 立项：候选药物 X 参比制剂的痛点 + 脂质体解决方案
- 中期：制剂表征完成 + 体外释放数据 + 初步PK数据
- 结题：完整PK/BD/排泄数据 + 脂质体优势结论

### 展示层次
1. **一句话**: 用一句话说清你的核心发现
2. **一分钟**: 展开讲问题→方案→关键数据
3. **十分钟**: 完整故事线
4. **书面版**: 论文/申报书
