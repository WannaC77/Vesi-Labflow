# 07 — 排泄与代谢工作流

> 触发：排泄、代谢、清除、胆汁、尿液、粪便、肠肝循环、代谢物

---

## 排泄实验总览

```
① 实验方案设计（动物/收集方法/时间点）
    ↓
② 代谢笼准备
    ↓
③ 给药后定时收集尿液/粪便/胆汁
    ↓
④ 样品处理（提取/检测）
    ↓
⑤ 排泄率计算（%给药量）
    ↓
⑥ 代谢物鉴定
    ↓
⑦ 脂质体 vs 参比制剂 排泄特征比较
```

## 排泄途径

### 候选药物 X 主要排泄途径

| 途径 | 主要形式 | 占比 | 说明 |
|------|---------|------|------|
| **胆汁排泄** | 候选药物 X + <结合代谢物> + <活性代谢物> | ~60-70% | 主要排泄途径 |
| **尿液排泄** | 候选药物 X + <结合代谢物> | ~20-25% | 次要途径 |
| **粪便排泄** | 候选药物 X/<活性代谢物>/<结合代谢物>（来自胆汁） | 随胆汁 | iv 给药时粪便即胆汁排泄的终末去向，不含"未吸收"概念 |

### 代谢途径

```
候选药物 X（母体药物）
    │
    ├──→ <活性代谢物>（活性代谢物，羧酸酯酶水解，肝脏/肠道）
    │        │
    │        └──→ <结合代谢物>（葡萄糖醛酸结合物，<UGT 酶>代谢，肝脏）
    │                 │
    │                 └──→ 肠道菌群β-葡萄糖醛酸酶水解 → <活性代谢物>（肠肝循环）
    │
    └──→ APC / NPC（CYP3A4氧化代谢，次要途径）
```

### 脂质体对代谢的影响

| 环节 | 脂质体预期影响 | 机制 |
|------|--------------|------|
| 候选药物 X→<活性代谢物> | 可能延迟 | 脂质体包裹→缓慢释放→肝脏代谢延迟 |
| <活性代谢物>→<结合代谢物> | 可能改变 | 释放速率影响代谢速率 |
| 胆汁排泄 | 可能延迟/改变 | 脂质体在肝脏蓄积→释放药物→排泄 |
| 尿液排泄 | 可能减少 | 脂质体包裹→肾小球滤过减少 |

## 实验设计

> ⚠️ **方案分层（2026-08-30）**：胆管插管为创伤性手术，本科条件下技术与伦理门槛高——
> **主方案 = 代谢笼粪尿收集 + 质量守恒**（胆汁路径靠文献讨论支撑，候选药物 X 胆汁排泄为主是文献共识）；
> 胆管插管列为**进阶可选**（仅当粪尿回收率异常且导师确认具备手术条件时启动）。

### 胆汁排泄实验（进阶可选）

#### 方法：胆管插管术

```
① 动物麻醉（异氟烷或戊巴比妥钠）
    ↓
② 腹部正中切口，暴露胆总管
    ↓
③ 胆总管远端插管（PE-10管）
    ↓
④ 缝合伤口，动物保温
    ↓
⑤ 给药（尾静脉注射）
    ↓
⑥ 定时收集胆汁（每2h收集一次）
    ↓
⑦ 记录胆汁体积
    ↓
⑧ HPLC/LC-MS/MS检测药物和代谢物
```

#### 胆汁收集时间点

| 时间段 | 0-2h | 2-4h | 4-6h | 6-8h | 8-12h | 12-24h |
|--------|------|------|------|------|-------|--------|
| 对应 | 分布相 | 消除早期 | 消除中期 | 消除中后期 | 消除后期 | 长循环 |

### 尿液排泄实验

#### 方法：代谢笼收集

```
① 动物放入代谢笼（禁食不禁水）
    ↓
② 给药（尾静脉注射）
    ↓
③ 定时收集尿液（每4h或每8h）
    ↓
④ 记录尿液体积
    ↓
⑤ 离心去沉淀（3000g × 10min）
    ↓
⑥ HPLC/LC-MS/MS检测
```

#### 尿液收集时间点

| 时间段 | 0-4h | 4-8h | 8-12h | 12-24h | 24-48h | 48-72h |
|--------|------|------|-------|--------|--------|--------|

### 粪便排泄实验

```
① 动物放入代谢笼
    ↓
② 给药
    ↓
③ 定时收集粪便（每12h或每24h）
    ↓
④ 粪便干燥称重
    ↓
⑤ 匀浆提取（加入甲醇或乙腈）
    ↓
⑥ 离心取上清，HPLC/LC-MS/MS检测
```

## 排泄率计算

### 累积排泄率

```
累积排泄率(%) = (Σ药物量) / 给药总量 × 100%

其中：
- 胆汁：Σ(Ci × Vi) / Dose × 100%
- 尿液：Σ(Ci × Vi) / Dose × 100%
- 粪便：Σ(Ci × Wi) / Dose × 100%

Ci = 第i个时间间隔的药物浓度
Vi = 第i个时间间隔的体积
Wi = 第i个时间间隔的粪便重量
Dose = 给药总量
```

### 同时测定目标物

| 化合物 | 意义 |
|--------|------|
| 候选药物 X | 未代谢母体药物 |
| <活性代谢物> | 活性代谢物 |
| <结合代谢物> | 结合代谢物（主要胆汁排泄形式） |

### 排泄平衡

```
排泄平衡 = 胆汁排泄% + 尿液排泄% + 粪便排泄% + 组织残留%

理想情况：总回收率 80-120%（考虑检测误差）
```

## 脂质体 vs 参比制剂 排泄比较

| 比较指标 | 脂质体预期 | 参比制剂预期 |
|---------|-----------|-----------|
| 胆汁排泄速率 | ↓ 延缓 | 基准 |
| 尿液排泄速率 | ↓ 减少 | 基准 |
| <活性代谢物>/<结合代谢物>比值 | 可能改变 | 基准 |
| 总排泄率 | 可能相当（延迟） | 基准 |
| 排泄达峰时间 | ↑ 延后 | 基准 |

## 肠肝循环验证（可选）

```
① 给药后收集胆汁（含<结合代谢物>）
    ↓
② 将胆汁灌胃给另一组动物
    ↓
③ 检测血浆中<活性代谢物>浓度
    ↓
④ 如果<活性代谢物>重新出现 → 肠肝循环确认
```

## 微陷阱速查

| 坑 | 后果 | 正确做法 |
|----|------|---------|
| 胆管插管失败 | 胆汁收集失败 | 预实验练习插管技术 |
| 胆汁收集不完整 | 排泄率偏低 | 确保插管通畅，定时检查 |
| 尿液体积测量不准 | 排泄率计算错误 | 用移液器精确量取 |
| 粪便提取不完全 | 药物损失 | 充分匀浆+多次提取 |
| 未测代谢物 | 遗漏<活性代谢物>/<结合代谢物> | 同时测候选药物 X/<活性代谢物>/<结合代谢物> |
| 代谢笼应激 | 动物行为异常影响排泄 | 适应期≥24h |
| 忽略个体差异 | 变异大 | ≥6只/组 |
