# 共享规范（各工作流通用）

> 所有工作流引用本文件的对应章节，不重复定义。
> **中性声明**：本产品不依赖任何特定 agent / CLI / 调度器；文中「会话 / 独立上下文」均指「任一次可复算的执行单元」，可由人或任意工具承担。

## 1. 质量门禁

### 正式交付物（申报书 / 实验方案 / 成套数据图表 / 论文 / 答辩材料 / 导师汇报）

交付前必须通过：

| 门禁 | 检查内容 | 未通过处理 |
|------|---------|-----------|
| **自查** | 对应工作流 checklist 逐条过 | 补齐缺失项 |
| **吸收回灌** | `workflows/D-ABSORB.md`：吸收覆盖率 <100% 且未豁免 | 补吸收 / 记豁免 |
| **对抗性审查** | 审稿人模式：找逻辑漏洞 / 数据不足 / 可疑假设 | 修复后重审 |
| **Claim-Evidence 核验** | 核心主张是否有证据（`templates/Claim-Evidence映射表.md`；❌ 主张打回） | 补证据 / 降级表述 |
| **决策日志** | 关键决策是否记录 | 补记 |
| **溯源检查** | 数据性结论是否标注来源 | 补标来源 |
| **三态标注** | 事实 / 推断 / 假设是否区分 | 补标 |

交付物头部附自查说明（格式：`[自查] 已通过XX工作流checklist，对抗性审查发现问题N个，已修复M个，待讨论K个`）。

### 日常任务（单次检索 / 单段修改 / 问答 / 跑个脚本 / 格式调整）

轻量门禁：三态标注 ✓ · 文献溯源（PMID/DOI）✓ · 对抗性审查 ✗ · 决策日志 ✗ · learnings 仅在「这次踩了值得记的坑」时追加。

## 2. 对抗性审查

交付前由审稿人模式执行：

| 维度 | 检查问题 |
|------|---------|
| **逻辑链** | 问题→方法→结果→结论有没有断裂？ |
| **数据充分性** | 结论的数据支撑够不够？n 够不够？ |
| **对照完整性** | 阳性 / 阴性 / 空白 / 材料对照都有吗？ |
| **替代解释** | 有没有其他可能的解释？ |
| **统计严谨性** | 方法选择正确吗？多重比较校正了吗？ |
| **结论边界** | 结论是否超出数据范围？ |
| **冷水检验** | 脂质体体内稳定性 / EPR 效应 / 释放行为的数据支撑？ |
| **可复现性** | 别人读了 Methods 能重复吗？ |

每条批评必须附修改方案。只批评不给方案的审查是耍流氓。

### 整改动机审计（台账 = `<校准台账>`，模板 `templates/校准台账模板.md`）

**分数 / 通过不是目标，材料更真实才是。** 每条整改落盘前必过三问：

1. **独立依据**——有不依赖「过审查」的科学 / 规范依据吗？「会被批评」不是依据。
2. **可证伪性保持**——整改后最坏实验 / 审稿结果仍能被方案自身识别为失败吗？冷水检验通过的结论不得因整改被回退。
3. **如实报告不变式**——实验方案不得因预期「不好看」而改；数据不得选择性报告；分析方案不得为「让结果显著」而改；预注册口径变更必须留修订记录。

红旗命中即禁落盘（详见 `<校准台账>`；为显著而改分析方案 / 删不利数据 = 学术不端前兆）。

### 评审进化链路（四机制 · 记录正本 = `<校准台账>`）

- **缺陷谱系扫描**：审查前过谱系表——通用七族（口径二义 / 统计-现实 / 编辑残留 / 跨文档 / 预期-判据互斥 / 纸面通胀 / 验算不过）+ **领域族自建**（示例：剂量换算 / NCA 自洽 / 形态口径 / 对照充分性 / 溯源漂移 / 单位交叉 / 样本量矩阵 / 方法最小字段 / 体外转化假象）。**强制步骤**：①表-图-文三方扫描（编号 / 标题 / 单位 / n 对齐）②方法参数最小字段表（离心力+时间+温度、LLOQ、批号、仪器型号、蛋白结合率数值+测定浓度点+是否浓度依赖）③样本量矩阵验算。
- **known-answer 锚（已知答案锚）**：定期盲审**已知答案锚样本** → 与答案键问题清单对质算覆盖率；**灵敏度门**未过（默认起点 70%，经验值须自行重校）或漏重大问题 = 评审灵敏度不合格 → 先重校评审组。机制正本 `references/outcome-anchor-protocol.md`。
- **盲区轮换**：连续 2 次同一视角零独立新发现 → 强制换视角或借调**独立审查员**；审查连续 2 次「零发现」= 灵敏度失效，强制跑已知答案锚标定。
- **标准版本化**：`<校准标准>` vN.M（自定编号），规范变更记 changelog。

## 3. 交接规范

工作流之间的交接物必须包含：

```markdown
## 交接记录
- **来源工作流**: [编号-名称]
- **目标工作流**: [编号-名称]
- **交接内容**: [具体文件/数据/结论]
- **状态**: [完成/部分完成/待验证]
- **待办**: [目标工作流需要做什么]
- **决策日志**: [相关决策编号]
```

## 4. 人机分工定义

| 角色 | 代号 | 含义 |
|------|------|------|
| **人** | 人 | 必须由用户本人完成，AI 不可替代 |
| **审** | 审 | AI 生成 / 执行，人审阅确认 |
| **自** | 自 | AI 自主完成，人仅查看结果 |

**不可替代项（「人」）**：实验操作 · 研究假设确定 · 方案最终批准 · 纳入综述最终决策 · 投稿前终审 · 优先级决策。

## 5. 三态标注

每个论断必须三选一标注：

| 标注 | 含义 | 示例 |
|------|------|------|
| **[事实]** | 有出处的数据 / 结论 | 「候选药物 X 的 pKa 为 <值> [事实, PMID: <…>]」 |
| **[推断]** | 基于事实的合理推断 | 「脂质体可能延长半衰期 [推断, 基于 PEG 化脂质体文献]」 |
| **[假设]** | 未经验证的猜测 | 「假设活性代谢物生成速率不因载体而变 [假设]」 |

## 6. 认知偏见检查点

数据分析时主动提醒：**确认偏见**（有没有不符合预期的数据点？）· **选择性报告**（差的那几次结果如何？）· **叙事偏见**（这个变化统计上显著吗？还是我们希望它显著？）· **锚定效应**（其他课题组是否得出不同结论？）· **幸存者偏差**（失败的实验不会发出来）· **权威偏见**（好期刊的论文样本量也可能只有 n=3——你怎么看？）· **沉没成本**（这条路可能走不通，继续还是换方向？）。

## 7. 溯源追踪

每个数据性结论必须标注来源，无来源不写：

| 结论类型 | 必须附带 |
|----------|----------|
| 文献数据 | PMID 或 DOI + 页码 / 图表号 |
| 实验数据 | 原始数据文件路径 + 日期 |
| 统计结果 | 检验名 + 统计量 + 自由度 + p 值 + 效应量 |
| PK 参数 | 计算方法（NCA / 房室）+ 软件 + 权重方案 |
| 推断 / 假设 | 明确标注 [推断] / [假设]，不与事实混淆 |

违反溯源的输出 = 不合格，退回重做。
