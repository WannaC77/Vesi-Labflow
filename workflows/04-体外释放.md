## 释放实验设计

### 释放介质选择

| 介质 | 模拟环境 | pH | 组成 | 用途 |
|------|---------|-----|------|------|
| PBS | 血浆/生理 | 7.4 | 磷酸盐缓冲液 | 基础释放（对照） |
| PBS+10%FBS | 血浆（含蛋白） | 7.4 | PBS+胎牛血清 | 模拟血液环境 |
| PBS+10%血浆 | 真实血浆环境 | 7.4 | PBS+动物血浆 | 最接近体内 |
| 弱酸缓冲液 | 肿瘤微环境 | 6.5-6.8 | 醋酸缓冲液 | 仅荷瘤模型需要（本课题默认正常动物，可选） |
| 溶酶体模拟液 | 溶酶体 | 4.5-5.0 | 含组织蛋白酶B | 仅细胞内释放机制研究需要（可选） |

### 释放方法选择

| 方法 | 原理 | 适用 | 优缺点 |
|------|------|------|--------|
| **透析袋法**（推荐） | 脂质体在透析袋内，药物释放到外相 | 脂质体 | 简单，但膜吸附可能影响结果 |
| 超滤离心法 | 离心分离脂质体和释放介质 | 快速 | 操作频繁，可能扰动体系 |
| 沉淀离心法 | 高速离心沉降脂质体 | 高浓度 | 脂质体可能不完全沉降 |

### 透析袋法详细步骤

```
① 准备透析袋（MWCO 10-14kDa，预处理去除甘油）
    ↓
② 内相：脂质体制剂（已知药物浓度）
    ↓
③ 外相：释放介质（体积≥内相10倍，保证漏槽条件）
    ↓
④ 37°C恒温振荡（100rpm）
    ↓
⑤ 定时取样（外相）→ 补加等体积新鲜介质
    ↓
⑥ HPLC/UV测定药物浓度
    ↓
⑦ 计算累积释放率
```

## 释放动力学模型

### 模型拟合

| 模型 | 方程 | 判定标准 | 适用场景 |
|------|------|---------|---------|
| **零级释放** | Q = k₀t | R²最高 | 恒速释放 |
| **一级释放** | ln(1-Q) = -k₁t | R²最高 | 浓度依赖释放 |
| **Higuchi** | Q = kH√t | R²最高 | 扩散控制释放 |
| **Korsmeyer-Peppas** | Q = kptⁿ | R²最高 + n值有意义 | 综合机制判断 |
| **Weibull** | Q = 1-exp[-(t/τ)^β] | R²最高 | 经验模型 |

### Peppas n值解读

| n值 | 释放机制 |
|-----|---------|
| n ≤ 0.43 | Fickian扩散（药物扩散为主） |
| 0.43 < n < 0.85 | 非Fickian扩散（扩散+骨架溶蚀协同） |
| n ≥ 0.85 | Case-II转运（骨架溶蚀为主） |

### 拟合工具
- Python: `scipy.optimize.curve_fit`
- DDSolver (Excel插件)
- Origin

## 累积释放率计算

```
累积释放率 (%) = (Cn × Vtotal + ΣCi × Vi) / (药物总量) × 100%

其中：
- Cn = 第n次取样时的药物浓度
- Vtotal = 外相总体积
- Ci = 第i次取样的浓度
- Vi = 每次取样体积
```

**铁律**: 必须考虑取样补液的体积校正，否则后期时间点浓度偏低

## 实验对照

| 对照 | 目的 |
|------|------|
| 游离候选药物 X 溶液 | 药物自身释放特性（无载体限制） |
| 空白透析袋+游离药 | 验证透析袋膜不影响药物透过 |
| 空白脂质体 | 排除脂质本身对检测的干扰 |
| 纯释放介质 | 空白基线 |

## 微陷阱速查

| 坑 | 后果 | 正确做法 |
|----|------|---------|
| 未补液 | 取样导致体积变化，后期浓度偏低 | 每次取样后补等体积新鲜介质 |
| 未达漏槽条件 | 释放受阻，曲线平台偏低 | 外相体积≥内相10倍，或定期更换介质 |
| 透析袋吸附 | 药物损失→释放率偏低 | 预饱和透析袋，做回收率验证 |
| 时间点太少 | 曲线拟合差，无法判断释放机制 | ≥10点，前期密后期疏 |
| 温度不恒定 | 释放速率波动大 | 恒温水浴/培养箱，定时检查温度 |
| 取样不混匀 | 数据变异大 | 取样前轻轻混匀外相 |
