# 材料吸收层（D-ABSORB · 通用接入点）

> 触发：凡涉及「喂样例 / 吸收材料 / 对标升级」的任务，按本文件路由到吸收基建。**本产品不依赖任何特定 agent / CLI / 调度器**。
> 本文件只定义**机制**；`<…>` 为**自建占位**，未自建时走清单式人工核验并标 `[降级]`。

## 一、吸收基建位置（唯一正本）

```text
<共享层>/                      （可自建）
  ├─ <吸收基准总表>.md     单一正本；产出定稿前必须回灌
  ├─ <负面迁移清单>.md     样例写了 ≠ 我方都写；收尾必添条目
  ├─ <锚集注册规程>.md     已知答案锚 / 已知档位锚 / 外部权威锚的登记与校准
  ├─ <吸收流水线>.md       批量吸收 SOP（每步有产物 + 核验）
  ├─ <锚注册卡>/           锚卡片目录（模板 `templates/锚注册卡模板.md`）
  ├─ scripts/<吸收门>.py       回灌 gate（覆盖率 <100% 且未豁免 → exit 1）
  └─ scripts/<图像吸收>.py     图像 / PDF 三件套（ocr / vision / meta）
```

## 二、吸收 gate：三态与双向 set diff 纪律

- **三态（不得跳步）**：**候选报告 → 复核 → 写正本**。批量流程**唯一允许**的写盘动作 = 产出「候选报告」；写入正本由人工或独立会话**定期复核**（写不写 / 表述 / 是否并入既有条目 / 复发计数）。
- **写入执行**：同批备份（`.bak-<批名>`）+ 计数**脚本直出** + **双向 set diff**（改动件 ↔ 备份件，两侧差集皆空）+ 回读校验。
- **覆盖率 gate**：产出目录回灌覆盖率 <100% 且未豁免 → 吸收门脚本（自建）exit 1。
- **积压不得静默**：候选报告连续 3 个复核周期未处理 → 报告顶部标「⚠️ 积压 N 期」。

## 三、吸收会话收尾固定输出（不得省）

```text
本批次吸收完成：清点 N 份 / 吸收卡 x 张 / 图像三件套 y 张 / 总表新增 z 条（共 W 条）/ 负面迁移 a 条 / 锚注册 b 张 / gate 覆盖率 q%
```

缺项即视为收尾不完整；**总表行数与负面迁移条目数是硬核验**。

## 四、与既有工作流的关系（不重复，不冲突）

- 锚校准读 `<锚集注册规程>`（自建）取锚全集，机制正本 `references/outcome-anchor-protocol.md`；`<校准台账>`（`templates/校准台账模板.md`）为版本化与整改历史正本。
- 产出定稿前新增一步「吸收回灌」，通过后才进自查 / 对抗性审查门禁（`workflows/_SHARED.md` §1–2）：数据 / 图表 → `workflows/08-数据处理与可视化.md`；论文 → `workflows/09-论文写作.md`；答辩材料 → `workflows/10-答辩准备.md`；实验方案 → `workflows/03`–`07`。
- 图三种来源：① 自绘图 ② 样例材料图（含扫描件 / 往届材料 PDF，强制走三件套）③ 过程文档图（历史记录不动）——本文件只新增 ② 的管道。
