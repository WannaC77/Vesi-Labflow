# 06 — 组织分布工作流

> 触发：分布、组织分布、靶向性、器官分布、活体成像、荧光标记、组织匀浆

---

## 组织分布实验总览

```
① 实验方案设计（动物/时间点/取材组织/检测方法）
    ↓
② 药物标记或直接检测
    ↓
③ 给药+定时取材（心脏/肝/脾/肺/肾/脑/肿瘤等）
    ↓
④ 组织处理（匀浆/提取/检测）
    ↓
⑤ 数据计算（μg药物/g组织）
    ↓
⑥ 脂质体 vs 参比制剂 组织分布比较
```

## 检测方法选择

| 方法 | 原理 | 优缺点 | 适用场景 |
|------|------|--------|---------|
| **LC-MS/MS直接测药** | 组织匀浆→蛋白沉淀→LC-MS/MS | 最准确，可同时测候选药物 X 和<活性代谢物> | **推荐**，金标准 |
| 荧光标记 | 脂质体标记荧光探针(DiR/DiD/Cy5.5) | 直观，但标记可能改变脂质体性质 | 活体成像+定性 |
| 放射标记 | ³H或¹⁴C标记药物 | 灵敏度最高 | 特殊需要 |

**本项目推荐**: LC-MS/MS直接测药（金标准）+ 荧光标记活体成像（辅助验证）

## 实验设计

### 取材时间点

基于PK数据选择（覆盖分布相+消除相）：

| 时间点 | 1h | 4h | 8h | 12h | 24h | 48h | 72h |
|--------|-----|-----|-----|------|------|------|------|
| 对应 | 分布相 | 消除早期 | 消除中期 | 消除中后期 | 消除后期 | 长循环特征 | 最终分布 |

**每个时间点**: 牺牲式取材（组织分布必须杀鼠取材），≥6只/组。
**空白对照组衔接注（2026-09-18）**：05-体内药代动力学设空白对照组 n=4（空白脂质体 iv），其定位=PK 基线/基质校准，**不计入本工作流取材矩阵**；如需组织本底测定（空白脂质体在组织的贡献），按需在 1–2 个关键时间点加取空白组（每点 ≥3 只），并在上方动物用量评估中单列报备——不得静默把空白组摊入 84 只预算之外。
⚠️ **动物用量与可行性评估**：7 时间点 × 2 组 × 6 只 = 84 只起——动物规模、经费（动物房按天计费）与伦理成本必须在方案阶段向导师/伦理委员会如实报备。缩减策略（按优先级）：
1. 时间点合并至 4-5 个（如 1/8/24/48/72h，依据 PK 半衰期覆盖分布相与消除相各 ≥2 点）；
2. 组织清单分层（★必取 6 项；★★肿瘤/脑仅荷瘤模型或特殊问题需要）；
3. 与 05-PK 共用动物不可行（取材即牺牲），但同批制备的脂质体可同时支撑两组实验，控制批间变异。

### 取材组织

| 组织 | 优先级 | 取材目的 |
|------|--------|---------|
| 心脏 | ★ | 心脏毒性评估 |
| 肝脏 | ★ | 首过效应/RES摄取/代谢 |
| 脾脏 | ★ | RES系统摄取 |
| 肺脏 | ★ | 肺分布 |
| 肾脏 | ★ | 肾排泄评估 |
| 脑 | ★ | 血脑屏障穿透（候选药物 X 相关毒性） |
| 肿瘤* | ★★ | 靶向性（如用荷瘤模型） |
| 血浆 | ★ | 同时采血，与PK数据对照 |

*注：如用正常动物，肿瘤组织不取。荷瘤模型可额外评估肿瘤靶向性。

### 脂质体 vs 参比制剂 比较

| 比较指标 | 脂质体预期 | 参比制剂预期 |
|---------|-----------|-----------|
| 肝脏浓度 | ↑↑ 显著增高 | 基准 |
| 脾脏浓度 | ↑↑ 显著增高 | 基准 |
| 肿瘤浓度 | ↑↑ 显著增高（如荷瘤） | 基准 |
| 心脏浓度 | ↓ 降低 | 基准 |
| 脑浓度 | 可能↓ | 基准 |

## 组织处理详细步骤

### 组织匀浆法（LC-MS/MS检测）

```
① 取材：牺牲动物，迅速取出目标组织
    ↓
② 称重：精确称量组织重量（记录湿重）
    ↓
③ 洗涤：用冰冷PBS冲洗血液
    ↓
④ 匀浆：加入3倍体积冰冷PBS（或含蛋白酶抑制剂）
    用组织匀浆器匀浆（冰上操作）
    ↓
⑤ 取100μL匀浆液
    ↓
⑥ 蛋白沉淀：加入300μL含内标的乙腈
    涡旋1min，离心12000g × 10min
    ↓
⑦ 取上清，LC-MS/MS检测
    ↓
⑧ 计算：μg药物 / g组织
```

### 内标选择

| 内标 | 适用 | 备注 |
|------|------|------|
| 美托洛尔 | 候选药物 X | 常用内标 |
| 坎地沙坦 | 候选药物 X | 替代内标 |
| 同位素标记候选药物 X (d10-候选药物 X) | 最佳 | 消除基质效应，但较贵 |

## 数据计算

### 组织药物浓度

```
Ctissue (μg/g) = (Cmeasured × Vextract) / Wtissue

其中：
- Cmeasured = LC-MS/MS测得浓度 (μg/mL)
- Vextract = 提取液体积 (mL)
- Wtissue = 组织湿重 (g)
```

### 靶向效率评估

```
靶向效率(%) = (AUC_脂质体组织 / AUC_脂质体血浆) / (AUC_参比制剂组织 / AUC_参比制剂血浆) × 100%

或简化为：
组织药物暴露比 = AUC_脂质体(组织) / AUC_参比制剂(组织)
```

## 荧光标记活体成像（辅助验证）

### 标记方法

```
① 制备脂质体时加入0.5-1 mol% DiR或DiD
    ↓
② 验证标记后粒径/PDI/EE%无显著变化
    ↓
③ 给药后在小动物活体成像系统(IVIS)拍摄
    ↓
④ 定时成像（1/4/8/12/24/48h）
    ↓
⑤ 终点取材，器官离体成像
    ↓
⑥ 定量分析荧光强度（平均辐射效率）
```

### 注意事项

| 注意 | 说明 |
|------|------|
| 荧光探针选择 | DiR/DiD（近红外，穿透深）|
| 标记浓度 | 0.5-1 mol%（过多改变膜性质） |
| 自发荧光 | 设未标记对照扣除背景 |
| 探针泄漏 | 验证24h内泄漏率<10% |
| 定量局限 | 荧光强度≠药物浓度，仅作定性/半定量 |

## 微陷阱速查

| 坑 | 后果 | 正确做法 |
|----|------|---------|
| 取材时间点不够 | 无法完整描述分布动力学 | 基于PK数据选≥5个时间点 |
| 组织未充分洗涤 | 残留血液→组织浓度偏高 | 冷PBS冲洗2-3次 |
| 匀浆不完全 | 组织中药物提取不完全 | 确认匀浆均匀，无可见组织块 |
| 未用内标 | 基质效应导致结果不准 | 每个样品加内标 |
| 组织称重不精确 | 浓度计算偏差 | 精确到0.001g |
| 忽略个体差异 | 变异大，统计power不足 | 每个时间点≥6只 |
| 荧光标记改变脂质体性质 | 标记后数据不可代表原制剂 | 标记后必须验证表征参数 |
