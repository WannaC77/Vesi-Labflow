# 08 — 数据处理与可视化工作流

> 触发：数据、统计、图表、绑图、可视化、分析、拟合、PK参数、热图

---

## 数据处理流程

```
① 原始数据备份（永不覆盖）
    ↓
② 数据清洗（标记异常值，不直接删除）
    ↓
③ 描述性统计（均值、SD、n）
    ↓
④ 正态性检验（Shapiro-Wilk）
    ↓
⑤ 选择统计方法（见下方速查）
    ↓
⑥ 假设检验（报告精确p值）
    ↓
⑦ 效应量计算（Cohen's d 等）
    ↓
⑧ 可视化（见下方图表规范）
    ↓
⑨ 审稿人模式自查（见下方checklist）
```

## 统计方法速查

| 场景 | 方法 | Python | GraphPad |
|------|------|--------|----------|
| 两组正态 | 独立t检验 | `scipy.stats.ttest_ind` | t-test |
| 两组非正态 | Mann-Whitney U | `scipy.stats.mannwhitneyu` | Mann-Whitney |
| 多组正态 | 单因素ANOVA+Tukey | `scipy.stats.f_oneway`（事后检验: `statsmodels.stats.multicomp.pairwise_tukeyhsd` 或 `scikit-posthocs`） | One-way ANOVA |
| 多组非正态 | Kruskal-Wallis+Dunn | `scipy.stats.kruskal`（事后检验: `scikit-posthocs.posthoc_dunn`） | Kruskal-Wallis |
| 重复测量 | 重复ANOVA/Friedman | `pingouin.rm_anova` | Repeated measures |
| 相关性 | Pearson/Spearman | `scipy.stats.pearsonr` | Correlation |
| 生存分析 | Kaplan-Meier+Log-rank | `lifelines` | Survival |
| PK参数比较 | 独立t检验/Mann-Whitney（AUC/Cmax 对数转换后比较） | `scipy.stats` | t-test |

**铁律**: 统计方法在实验前确定，非事后选择

## 统计微陷阱速查

| 坑 | 后果 | 正确做法 |
|----|------|---------|
| SD/SEM混淆 | 误差棒含义不明，审稿人质疑统计严谨性 | 统一用 SD 描述变异并叠加个体散点；SEM 仅用于表示均值置信度，且必须在图注声明 |
| n<3做统计 | 检验无效力（power）可言，"显著"结果多半是巧合 | ≥3独立生物学重复 |
| n=3 组间非参数比较 | Mann-Whitney 精确双侧 p 下限 = 2/C(6,3) = 0.10——任何数据都不可能 p<0.05，小样本「显著」标注必假 | 增大 n；或改报效应量+95%CI、措辞「呈趋势」；勿在小样本上标 */** |
| 多重比较未校正 | 假阳性率膨胀（20次两两比较约64%概率出假显著） | Bonferroni或Tukey |
| 异常值直接删 | 等同选择性报告，破坏数据完整性 | Grubbs/ROUT，说明理由 |
| "n=3"是同瓶测三次 | 技术重复冒充生物学重复，全部统计推断无效 | 必须独立制样/培养 |
| 没做power analysis | 样本量不足，阴性结论不可信（分不清"无效"还是"没测出"） | G*Power估算样本量 |
| 不检验正态性 | 参数检验误用，p值失真 | 先Shapiro-Wilk再选方法 |
| PK小样本强结论 | n=6-8/组下个体变异（CV常>30%）易淹没组间差异 | 结论表述克制（"呈趋势"），报告效应量与置信区间 |

> 2026-09-18 补：n=3 非参数双侧 p 下限 = 2/C(6,3) = 0.10 条。

## 本项目专用图表类型

### 1. 血药浓度-时间曲线

```
X轴: 时间 (h)，对数刻度或线性
Y轴: 药物浓度 (ng/mL)，对数刻度
两条曲线: 脂质体组 vs 注射液组
误差棒: SD + 个体散点
```

### 2. 组织分布热图(Heatmap)

```
行: 组织（心/肝/脾/肺/肾/脑）
列: 时间点（1/4/8/12/24/48/72h）
颜色: 药物浓度 (μg/g)
两组并排: 脂质体 vs 注射液
```

### 3. PK参数柱状图

```
X轴: PK参数（AUC/Cmax/t1/2/MRT/CL/Vd）
Y轴: 参数值
两组并排: 脂质体 vs 注射液
显著性标注: *p<0.05, **p<0.01
```

### 4. 累积排泄率曲线

```
X轴: 时间 (h)
Y轴: 累积排泄率 (%)
多条曲线: 胆汁/尿液/粪便/总排泄
两组对比: 脂质体 vs 注射液
```

### 5. 体外释放曲线

```
X轴: 时间 (h)
Y轴: 累积释放率 (%)
拟合曲线 + 实测点
释放动力学模型标注
```

### 6. 制剂表征图

```
粒径分布图(DLS): 单峰，PDI<0.2
TEM/Cryo-TEM图: 球形脂质体
Zeta电位图: 峰位一致
```

## 图表制作标准

### 必须项
- 误差棒（统一用 SD 并叠加个体散点；SEM 仅限表示均值置信度且须在图注声明）
- 样本量（n=3, n=5...）
- 统计显著性（\*p<0.05, \*\*p<0.01, \*\*\*p<0.001，报告精确p值）
- 坐标轴带单位
- 图注自含（不看正文也能理解）

### 配色
- 色盲友好：viridis、ColorBrewer、Blue-Orange
- 避免红绿搭配
- 同一论文配色统一

### 分辨率
- 最终输出 ≥300 DPI
- 格式：TIFF（位图）或 PDF（矢量）

---

## 常见图表错误（必须避免）

| 错误 | 为什么错 | 正确做法 |
|------|---------|---------|
| 3D饼图 | 扭曲比例感知 | 用水平柱状图 |
| 双Y轴 | 误导关联性 | 分成两张子图 |
| Y轴不从0 | 夸大差异 | 从0开始，或用break标注 |
| 箱线图点重叠 | 看不清分布 | violin plot 或 jitter |
| 红绿配色 | 色盲看不见 | 蓝橙替代 |
| SEM掩盖个体差异 | n小时误导 | 叠加散点 |
| 分辨率不足 | 打印模糊 | ≥300 DPI |
| 字体太小 | 缩印不可读 | ≥10pt（缩印后） |

---

## 图表叙事原则

- **一图一故事**: 每张图只讲一个核心信息
- **排列按逻辑**: 论证逻辑线，非实验时间线
- **图注自含**: Figure legend独立可理解
- **最有力的先放**: Figure 1决定读者是否继续看

### LS-8-1 自报计数必须逐条复点（复发 3 次 · 最高频）

**现象**：清单自带汇总表与正文逐条实点不符（「重大 25/一般 5」vs 实点「4/23/7」）；头部数字把复评件混进 holdout 分母（n=14/85.7% vs 独立集 n=12/91.7%）；脚本打印句口径与报告正文不一致。
**根因**：汇总靠"记忆/估算"生成，未做机械复点。
**执行要求**：
- 任何「共 N 条 / 分 M 类」的汇总句，**必须由逐条计数生成**，不得手写
- 台账落笔时以**逐条实点为准**；若汇总与实点不符，改汇总不改实点
- 报告头部数字与脚注/脚本输出**必须同源**，任一处不一致即退回

### LS-8-2 机械预检只查「存在」不查「位置」（复发 2 次）

**现象**：验收只查 `State=Ready` 未实跑；断言「37℃ 在正文」而实际在图 3 内（假 FAIL）；已知假命中白名单未建导致误报。
**执行要求**：
- 断言式检查必须落到**具体位置**（段落号 / 文件 / 图号），不接受「全文存在」
- 真 FAIL 与假 FAIL 分开记；假 FAIL 须**留证**（md5 / OCR 双证）并入白名单
- 声称"完成"必须附 **实跑证据**（输出文件 mtime / 运行日志 / 产物哈希）

### LS-8-3 跨日追加式报告必另立独立条目（复发 2 次）

**现象**：迁移报告追加进名为「08-30」的旧文件且未落决策日志，用户找不到；跨日后文件名撒谎。
