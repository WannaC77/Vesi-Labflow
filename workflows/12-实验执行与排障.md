# 12 — 实验执行与排障工作流（贯穿 03-07 所有实验环节）

> 触发：做实验、实验失败、结果不对、排障、调试、数据记录
> 定位：本工作流是 03-07 各实验环节共用的执行规范（记录/排障/复盘），领域微陷阱已分流至各主题工作流（03 表征 / 04 释放 / 05 PK·生物分析 / 06 分布 / 07 排泄）

---

## 实验前检查

每次实验开始前确认：
- [ ] 方案已审阅，步骤清晰
- [ ] 试剂在有效期内，浓度已确认
- [ ] 仪器已预约，参数已确认
- [ ] 对照组已设计好
- [ ] 数据记录模板已准备
- [ ] 安全注意事项已确认

---

## 实验记录规范

```markdown
## 实验记录: [名称]
- **日期**: YYYY-MM-DD
- **操作人**: [姓名]
- **目的**: 验证什么/获取什么数据
- **材料**:
  - [试剂, 货号, 批号, 厂家]
  - [细胞系, 代数, 来源]
- **仪器**: [型号, 参数]
- **环境**: 温度__°C, 湿度__%
- **步骤**（每步标参数）:
  1. [精确描述]
  2. ...
- **原始数据**: [存放路径]
- **结果**: [关键数值/观察]
- **异常**: [不符合预期的观察]
- **结论**: [说明了什么]
- **下一步**: [基于本次结果]
```

### 数据管理
- **原始数据**：永不删除/覆盖
- **命名规则**: `[日期]_[类型]_[样品]_[版本]`
- **备份**: 本地+云盘至少2份
- **溯源链**: 原始→处理→图表，每步记录

## 排障框架

实验不符预期时，按顺序排查：

| 层级 | 检查项 | 常见问题 |
|------|--------|---------|
| **1.操作** | 步骤是否严格按方案？ | 顺序错误、遗漏步骤、时间不准 |
| **2.试剂** | 有效期？浓度？溶剂？批次？ | 过期、配错浓度、换批未验证 |
| **3.仪器** | 校准？参数？ | 未校准、参数漂移 |
| **4.对照** | 阳性正常？阴性干净？ | 对照本身异常→实验无效 |
| **5.生物** | 动物状态正常？制剂批间一致？ | 动物应激/体重异常、脂质体批间变异、样品冻融失控 |
| **6.设计** | 假设是否成立？ | 回到方案重新审视 |

### 排障记录
每次排障必须记录：
1. 现象描述（具体、可量化）
2. 排除了什么（及排除依据）
3. 最可能的原因
4. 验证方案
5. 最终结论

## 失败复盘模板

```markdown
## 失败复盘: [实验名称]
- **日期**: YYYY-MM-DD
- **目的**: 预期验证什么
- **预期结果**: 应该看到什么
- **实际结果**: 看到了什么（附原始数据）
- **差异**: 预期与实际的差距
- **可能原因**（≥3个）:
  1. [最可能] — 证据
  2. [次可能] — 证据
  3. [设计层面] — 假设是否成立
- **验证计划**: 下一步做什么确认原因
- **结论**: [事后回填]
- **教训**: [事后回填]
```

## 认知偏见检查点

数据分析时按 [_SHARED.md §认知偏见检查点](_SHARED.md) 执行（唯一正本，勿在此重复维护）。复盘与排障场景高频触发的三项：确认偏见（"有没有不符合预期的数据点？"）、幸存者偏差（"失败的实验不会发出来"）、沉没成本（"数据显示这条路可能走不通，继续还是换方向？"）。
