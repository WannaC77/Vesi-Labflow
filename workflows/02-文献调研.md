# 02 — 文献调研工作流

> 触发：文献、检索、精读、综述、证据、引用、参考文献

## 检索策略

### 数据源优先级
1. **PubMed** — 生物医学首选（MeSH检索）
2. **Google Scholar** — 跨学科+最新预印本
3. **Web of Science** — 引用追踪+高影响力筛选
4. **CNKI/万方** — 中文目标赛道相关政策+国内进展
5. **Zotero** — 已有文献库内检索

### 检索词构建

#### 核心检索式
```
# 候选药物 X 脂质体
(候选药物 X OR <活性代谢物>) AND (liposome OR liposomal) AND (pharmacokinetics OR biodistribution OR tissue distribution OR excretion)

# 脂质体体内行为
liposomal AND (in vivo release OR sustained release OR controlled release) AND (plasma OR serum)

# 组织分布比较
(候选药物 X) AND (liposome) AND (tissue distribution OR organ distribution OR tumor accumulation)

# 排泄
(候选药物 X OR <活性代谢物>) AND (excretion OR elimination OR biliary OR renal) AND (liposome OR liposomal)
```

#### MeSH词
- Irinotecan [MeSH]
- Liposomes [MeSH]
- Drug Liberation [MeSH]
- Tissue Distribution [MeSH]
- Metabolic Clearance Rate [MeSH]
- Biliary Excretion [MeSH]

### 筛选流程
```
标题筛选（快速排除明显不相关）
    ↓
摘要筛选（保留体内PK/BD/排泄相关）
    ↓
全文精读（核心文献30-50篇）
    ↓
纳入综述（最终引用15-25篇）
```

## 证据等级评价

```
         ┌─────────────────┐
         │  系统综述/Meta  │  ← 最高权重
         ├─────────────────┤
         │    RCT/临床试验  │
         ├─────────────────┤
         │  队列/病例对照   │
         ├─────────────────┤
         │  体外/动物实验   │  ← 本项目主要来源
         ├─────────────────┤
         │  病例报告/预印本  │
         ├─────────────────┤
         │   专家意见/综述   │  ← 最低权重
         └─────────────────┘
```

### 引用质量审查
| 检查项 | 标准 |
|--------|------|
| 样本量 | ≥3独立重复，动物≥6只/组 |
| 对照设计 | 有阳性对照（参比制剂（游离药））+ 阴性对照（空白脂质体） |
| 统计方法 | 方法匹配数据类型，多重比较已校正 |
| 独立验证 | 是否有其他实验室重复 |
| 时效性 | 近5年≥60%，经典文献≤20% |

### 灌水/造假信号
- 数据过于完美（无变异）
- 结论远超数据支撑范围
- 同一数据拆多篇发
- p值刚好<0.05多次
- 图片重复使用

### 矛盾文献处理
两篇结论相反时：
1. 比较样本量、实验条件、统计方法
2. 优先引用质量更高的
3. 无法判断时两篇都引，指出矛盾

## 候选药物 X 脂质体领域文献地图

按以下维度分类整理文献：

| 维度 | 分类 |
|------|------|
| 药物 | 候选药物 X（母体药）、<活性代谢物>、<结合代谢物> |
| 制剂类型 | 传统脂质体、PEG化脂质体、阳离子脂质体、温度敏感脂质体 |
| 脂质组成 | DPPC/DSPC/胆固醇/DSPE-PEG/磷脂酰丝氨酸 |
| 体内行为 | 血浆PK、组织分布、胆汁排泄、肾排泄、肠肝循环 |
| 检测方法 | LC-MS/MS、HPLC-UV、荧光标记、放射标记、活体成像 |
| 动物模型 | 小鼠、大鼠、荷瘤鼠、正常鼠 |
| PK参数 | AUC、Cmax、t1/2、MRT、CL、Vd、相对生物利用度 |

## 与知识库联动

- 新文献精读笔记 → 存入 `01-文献调研/精读笔记/`
- 关键概念 → 织入知识库（`kb/`）
- 每篇笔记必须有≥2条出链（关联已有概念）+ 回链
- 术语用英文原文，首次出现附中文译注
