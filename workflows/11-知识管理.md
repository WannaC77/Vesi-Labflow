## 决策日志

### 触发时机
**正式交付物定稿时**，或**不可逆决策**（花大钱、动动物、定技术路线）时。日常任务不记。

### 存放位置
`<本机路径>`（目录重组后正本，勿用旧路径 `Desktop\目标赛道-候选药物 X\`）

### 模板

```markdown
## 决策记录: [标题]
- **日期**: YYYY-MM-DD
- **内容**: 选择了X方案
- **备选**: A / B / C
- **选X理由**: 基于XX文献/数据/可行性
- **排除理由**: A不行因为…，B不行因为…
- **风险**: X可能在XX环节出问题
- **验证**: 预计在XX实验中验证
- **结果**: [事后回填]
- **教训**: [事后回填]
```

## 本项目关键决策点

| 决策点 | 备选 | 决策依据 |
|--------|------|---------|
| 脂质组成 | DPPC vs DSPC + 胆固醇比例 | 相变温度、稳定性、文献支持 |
| PEG化 | DSPE-PEG2000比例 | 循环时间 vs 膜稳定性权衡 |
| 载药方法 | 硫酸铵梯度 vs 薄膜水化 | EE%、药物稳定性 |
| 动物模型 | 正常鼠 vs 荷瘤鼠 | 研究目的（PK比较 vs 靶向性） |
| 检测方法 | LC-MS/MS vs HPLC-UV | 灵敏度、同时测代谢物能力 |
| 排泄实验 | 仅尿液 vs 胆汁+尿液+粪便 | 完整性 vs 可行性 |

## 经验教训融合

### 流程
```
任务结束
    ↓
提炼经验教训（什么work了？什么没work？为什么？）
    ↓
存入决策日志
    ↓
融合到长期记忆（MEMORY工具）
    ↓
后续对话自动引用
```

### 记忆分类
| 类型 | 示例 | 存储位置 |
|------|------|---------|
| 实验条件 | "脂质体制备60°C水化效果最好" | MEMORY |
| 失败教训 | "硫酸铵浓度300mM时EE%最高" | 决策日志+MEMORY |
| 方法偏好 | "导师偏好GraphPad而非Python绑图" | MEMORY |
| 工具经验 | "DDSolver拟合释放曲线R²最高" | MEMORY |
| PK计算 | "二室模型AIC最小，适合脂质体PK" | MEMORY |

## 跨会话记忆策略

每次对话开头：
1. 回顾上次进展（"上次你在优化XX，结果怎么样？"）
2. 检查是否有待回填的决策日志（结果/教训）
3. 检查项目健康度（对照01-项目管理的指标）

## 知识库维护

### 联动规则
- 新文献 → 精读笔记存入 `01-文献调研/`
- 关键概念 → 织入知识库（`kb/`，Obsidian vault；页面清单见其 index.md）
- 每篇笔记 ≥2条出链 + 回链
- 决策日志中引用的文献 → 同步到知识库

### 命名规范
- 精读笔记：`[PMID]_[第一作者]_[年份]_[关键词].md`
- 决策日志：`[YYYY-MM-DD]_[决策标题].md`
- 失败复盘：`[YYYY-MM-DD]_[实验名称]_复盘.md`

## 定期回顾

### 每月
- 回顾决策日志：当初的假设验证了吗？
- 检查行为模式：有没有反复出现的问题？
- 更新项目健康度指标

### 每阶段结束
- 全面复盘：做了什么、学到什么、下阶段注意什么
- 更新MEMORY中的长期经验
- 清理过时的临时记录
